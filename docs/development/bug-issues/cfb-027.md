# CFB-027: Scan next actions do not offer batch extinguish

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | ux |
| Area | `scan --json` next_actions |
| Observed while | `ExperimentRunbookGenerator` 追加で6 open firesを処理 |

## Observation

`scan --json` は個別の `context --fire` と `extinguish FIRE-*` を提示するが、複数fireがある場合もbatch templateを提示しない。

## Reproduction

```bash
codefire scan . --json
```

## Why It Matters

AI agentが毎回手製のbatch YAMLを生成する必要があり、fire数が増えるほど操作量とIDミスのリスクが増える。

## Workaround

`jq` でfire IDを抽出して `extinguish --batch` 用YAMLを作る。

## Candidate Fix

next_actionsに `extinguish --batch-template` またはbatch file生成相当の候補を追加する。

## Acceptance Criteria

- open fireが2件以上ある場合、batch消火のnext actionが出る。
- batch actionには共通evidenceを入れる場所が分かる。

## Evidence

- `scan --json` returned 4 changed atoms / 6 open fires and individual extinguish actions only.
