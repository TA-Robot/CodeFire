# CFB-058: `branch show --json` returns a plain unsupported error

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |
| Type | automation-json |
| Area | branch |
| Observed while | looking for branch detail state during dogfooding |

## Observation

`codefire branch show --path . --json` returns `error: unsupported branch command: show` as plain text and exits 2.

## Reproduction

```bash
codefire branch show --path . --json
```

## Why It Matters

Automation can list branches but cannot request a structured branch detail view or receive a structured unsupported-command diagnostic.

## Workaround

Fixed. Use `codefire branch show [branch] --json`.

## Candidate Fix

Implemented `branch show --json` and structured JSON failure envelopes for unsupported branch subcommands.

## Fix

- `branch show --path <open-dir> --json` returns `codefire_branch_detail`.
- Optional branch argument allows `branch show <branch> --json`.
- The payload includes name, head, state, sealed validation status, and opened registry summary.
- `branch --json` and other unsupported branch subcommands with `--json` return a command_result failure envelope instead of plain text only.

## Acceptance Criteria

- Unsupported branch subcommands with `--json` return a JSON envelope.
- If `branch show` is implemented, it includes branch name, head, sealed validation status, and open registry summary.
