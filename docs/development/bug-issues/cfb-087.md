# CFB-087: extinguish dry-run with missing evidence-ref ignores JSON envelope

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |
| Type | ux |
| Area | Extinguish / JSON Failure |
| Observed while | algorithm cycle 3 FrontierExperimentPlanner fire resolution preflight |

## Observation

`codefire extinguish <fire> --evidence-ref <missing> --dry-run --json` exits with a plain text object lookup error instead of a `codefire.command_result.v1` failure envelope.

Observed:

```text
error: object not found: CF-EVIDENCE-does-not-exist
```

## Reproduction

```bash
cd subprojects/algorithm-evolution-agent-lab
codefire scan --path . --json
codefire extinguish FIRE-36294136682A \
  --path . \
  --resolution implemented \
  --rationale "probe dry run" \
  --evidence-ref CF-EVIDENCE-does-not-exist \
  --dry-run \
  --json
```

## Why It Matters

Dry-run is the safe preflight path for automation. If a missing evidence reference bypasses the JSON envelope, an AI tool cannot classify the failure, identify the missing evidence ID, or recover by creating evidence first.

## Workaround

Check evidence object existence separately before using `--evidence-ref`, or parse the plain text error.

## Candidate Fix

Route evidence reference lookup failures through the same JSON failure envelope used by other `--json` command failures. The diagnostic should include the missing evidence ID, the fire ID, and whether the command was dry-run.

## Acceptance Criteria

- Missing evidence refs with `--json` return `ok:false` command result JSON.
- The diagnostic contains the missing evidence ID.
- Dry-run failure does not mutate fire or resolution ledgers.

## Evidence

- Observed on 2026-06-07 while preflighting `FrontierExperimentPlanner` fire resolution.

## Fix

Implemented in the active burn-down batch.

- Added a typed `MissingEvidenceRef` CLI error.
- JSON extinguish paths now render `codefire.command_result.v1` with `ok:false`, exit code 21, diagnostic `kind:"missing_evidence_ref"`, and recovery next actions.
- Evidence-ref success behavior from CFB-086 remains unchanged.
