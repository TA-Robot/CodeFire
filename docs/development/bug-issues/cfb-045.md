# CFB-045: Diff options report impact false while impact payload is present

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | low |
| Type | automation-json |
| Area | `diff --json` |
| Observed while | running `diff main main --json` |

## Observation

Diff output includes an `impact` object while `options.impact` is false.

## Reproduction

```bash
codefire diff main main --json
```

## Why It Matters

Automation cannot tell whether impact was requested, computed by default, or accidentally included.

## Workaround

Treat payload presence as authoritative.

## Candidate Fix

Align `options` flags with emitted sections or add explicit `included_sections`.

## Acceptance Criteria

- Options accurately describe which sections are present.
- Default included sections are documented in JSON.

## Evidence

- Output had `options.impact=false` and an `impact` object containing missing link state.
