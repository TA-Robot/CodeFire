# CFB-019: Fire display IDs need stable identity

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |
| Type | ux |
| Area | UX / Fire Identity |
| Observed while | Repeated algorithm feature additions produced `FIRE-001..010` style IDs each cycle |

## Observation

Sequential fire display IDs were reused across scans, making logs and conversations ambiguous.

## Impact

An operator referring to `FIRE-001` could mean different fires from different scan generations.

## Fix

Scan-generated fires now use digest-derived stable display IDs and expose stable fire UIDs in text output.
