# CFB-063: Review-pack and patch export lack JSON automation surfaces

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | automation-json |
| Area | review-pack / patch export |
| Observed while | checking review and patch automation commands |

## Observation

`review-pack main --json` and `patch export main --json` return unsupported option errors as plain text.

## Reproduction

```bash
codefire review-pack main --json
codefire patch export main --json
```

## Why It Matters

Review-pack and patch export are natural automation handoff commands. Without JSON, agents cannot inspect generated artifact paths, included sections, or failure diagnostics through a stable contract.

## Workaround

Use text/file output and infer artifact paths manually.

## Candidate Fix

Add JSON result or dry-run plan output for review-pack and patch export. If JSON is intentionally unsupported, unsupported-option failures should still be JSON when requested.

## Acceptance Criteria

- JSON mode returns artifact path, base/source targets, included sections, and diagnostics.
- Unsupported option paths are structured.

## Evidence

- Commands returned `error: unsupported review-pack option: --json` and `error: unsupported patch export option: --json`.
