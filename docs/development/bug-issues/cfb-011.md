# CFB-011: Verify output cannot directly generate an extinguish batch

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |
| Type | ux |
| Area | Extinguish Batch |
| Observed while | Processing many open fires with the same evidence |

## Observation

`verify --details` showed open fire IDs, but CodeFire did not provide a first-class way to turn the current open fire set into an `extinguish --batch` file.

## Impact

Operators had to hand-build JSON/YAML or shell loops, which increased the risk of missing a fire ID or applying inconsistent evidence.

## Fix

`codefire extinguish --batch-template` now reads the current open directory and emits a strict JSON batch wrapper accepted by `codefire extinguish --batch`.

It supports defaults for:

- `--resolution`
- `--rationale`
- `--evidence`
- `--evidence-ref`
- `--output`

## Evidence

- `cargo test -p codefire-cli --bin codefire-rs extinguish_batch_template -- --nocapture`
