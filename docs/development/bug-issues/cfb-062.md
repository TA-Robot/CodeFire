# CFB-062: Diff target resolution failures ignore `--json`

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | high |
| Type | automation-json |
| Area | diff |
| Observed while | probing diff failure paths during dogfooding |

## Observation

`codefire diff main DOES-NOT-EXIST --json` returns a plain text unknown branch error.

## Reproduction

```bash
codefire diff main DOES-NOT-EXIST --json
```

## Why It Matters

Diff is a core review and automation command. Target resolution failures should be machine-readable so agents can list branches or correct the target.

## Workaround

Fixed. Diff target resolution failures in JSON mode now return command result diagnostics.

## Candidate Fix

Implemented. Commitish/branch resolution failures are wrapped in JSON envelopes when `--json` is requested.

## Fix

- `diff --json` catches target resolution errors and returns `ok:false` command_result envelopes.
- Unknown branch errors include a `list_branches` next action.
- Non-JSON diff text behavior remains unchanged.

## Acceptance Criteria

- Unknown branch/commitish in diff returns JSON diagnostics.
- Diagnostic includes the missing target and a next action to list branches.

## Evidence

- Command returned `error: unknown branch: DOES-NOT-EXIST`.
- Fixed on 2026-06-10 in the global burn-down pass.
- Regression coverage: `show_and_diff_local_branches`.
