# CFB-062: Diff target resolution failures ignore `--json`

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | high |
| Type | automation-json |
| Area | diff |
| Observed while | probing diff failure paths during dogfooding |

## Observation

`codefire diff main DOES-NOT-EXIST --json` returns a plain text unknown branch error.

## Reproduction

```bash
codefire diff main DOES-NOT-EXIST --json
```

## Why It Matters

Diff is a core review and automation command. Target resolution failures should be machine-readable so agents can list branches or correct the target.

## Workaround

Run `branch list --json` before diff.

## Candidate Fix

Wrap commitish/branch resolution failures in JSON envelopes when `--json` is requested.

## Acceptance Criteria

- Unknown branch/commitish in diff returns JSON diagnostics.
- Diagnostic includes the missing target and a next action to list branches.

## Evidence

- Command returned `error: unknown branch: DOES-NOT-EXIST`.
