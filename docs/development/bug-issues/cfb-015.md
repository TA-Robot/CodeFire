# CFB-015: Clean verify should preserve open-clean status

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |
| Type | ux |
| Area | UX / State Label |
| Observed while | Running `verify --details --blocking-only` on a clean algorithm branch |

## Observation

A clean branch could move from `open-clean` to `open-consistent` after a successful verify, even though no source changes or fires existed.

## Impact

State labels appeared command-dependent rather than repository-dependent.

## Fix

Successful clean verification preserves `open-clean`.

## Evidence

- Global burn-down state reducer fixes.
- `current-cycle-burn-down-plan.md` CFB-015 entry.
