# CFB-122: open-target containment is lexical and can miss symlink or dot-dot escapes

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | high |
| Type | bug |
| Area | Path safety / Open target |
| Observed while | 2026-07-11 source/security boundary audit before new product development |

## Observation

Rust `absolute_path` joins a relative path to the current directory without normalization, and `ensure_open_target_allowed` relies on lexical `starts_with` relationships. A path that begins under the allowed workspace but traverses `..`, or an allowed-looking existing ancestor that is a symlink to an outside directory, is not resolved and rechecked at the use boundary.

## Reproduction

In a disposable workspace, create an allowed directory containing a symlink to an outside target and try an `open --dry-run` path below that link. Also test an allowed-prefix path containing `..`. No mutating reproduction should be run against user work.

## Why It Matters

Open materializes a full branch tree. A lexical containment decision can write outside the configured workspace, cross another open directory, or make cleanup/authority ambiguous for humans and agents.

## Workaround

Use normalized sibling paths with no symlink component or `..`, and inspect the real path of every existing ancestor before apply. Keep open dry-runs read-only.

## Candidate Fix

Introduce one canonical path-boundary resolver that canonicalizes the deepest existing ancestor, rejects symlink components according to policy, appends only validated non-existing suffixes, and rechecks the resolved target against repository/workspace and existing-open boundaries immediately before use.

## Acceptance Criteria

- `..`, symlink-to-outside, symlink-into-another-open, and prefix-collision paths are rejected in dry-run and apply.
- A normal non-existing sibling target remains supported.
- Validation and use share the same resolved subject or detect a race and fail closed.
- JSON diagnostics include the requested path, resolved boundary evidence where safe, and a non-destructive next action.

## Evidence

- `crates/codefire-cli/src/main.rs::absolute_path`
- `crates/codefire-cli/src/main.rs::ensure_open_target_allowed`
- Stage 1 path/symlink red-team item in the modernization roadmap
