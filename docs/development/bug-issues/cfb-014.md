# CFB-014: Status must not report consistent when fires are open

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |
| Type | bug |
| Area | UX / State Label |
| Observed while | Scanning new `ConfigurationCapture` and `RunIdentityLedger` changes |

## Observation

Immediately after `scan` opened fires, `status` could report `open-consistent` while also showing a positive open fire count.

## Impact

The branch looked consistent even though it required fire review and extinguish work.

## Fix

Status derivation now treats any positive open fire count as a burning state.

## Evidence

- Global burn-down state reducer fixes.
- `current-cycle-burn-down-plan.md` CFB-014 entry.
