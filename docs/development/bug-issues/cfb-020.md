# CFB-020: Extinguish success output lacks target context

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |
| Type | ux |
| Area | Extinguish Output |
| Observed while | Reviewing logs after repeated fire resolution |

## Observation

The text success output only reported the fire ID, so a later log reader had to correlate with a previous scan to know which source/target pair was resolved.

## Impact

Extinguish logs were weak audit evidence during dogfooding and agent operation.

## Fix

Single-fire extinguish output now includes:

- display ID
- fire UID
- source atom
- target atom
- remaining open fire count

Batch extinguish output now includes the processed count, remaining open fire count, and a bounded list of resolved fire source/target pairs.
