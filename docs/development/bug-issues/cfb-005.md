# CFB-005: Extinguish rationale and evidence input is too heavy

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |
| Type | ux |
| Area | Extinguish UX |
| Observed while | Repeated dogfood extinguish operations in `algorithm-evolution-agent-lab` |

## Observation

Resolving many fires required repeating `--rationale`, `--evidence`, or `--evidence-ref` text across single-fire commands.

## Impact

The human or AI operator spent more effort creating shell loops and repeated text than reviewing the actual trace-change evidence.

## Fix

CodeFire now supports a higher-level extinguish workflow:

- `codefire extinguish --interactive --json` returns open fires, recent evidence candidates, and draft commands.
- `codefire extinguish --all-matching "SOURCE -> TARGET"` applies the same resolution evidence to matching source/target fires.
- `codefire extinguish --batch-template` generates a strict JSON batch wrapper from current open fires.

## Evidence

- `cargo test -p codefire-cli --bin codefire-rs extinguish_batch_template -- --nocapture`
- Existing tests cover interactive and all-matching extinguish flows.
