# CFB-068: scan next_actions drop the explicit path context

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | automation-contract |
| Area | Automation JSON / Next Actions Path |
| Observed while | adding `ClaimReviewQueue` in the algorithm dogfood project |

## Observation

`codefire scan --path . --json --metrics` was run from the algorithm open directory. The returned `next_actions` suggested commands such as `codefire context --changed --json`, `codefire verify --details --json`, and `codefire extinguish FIRE-* ...` without preserving the original `--path .` or including a machine-readable `open_dir` / `path` field in every action target.

## Reproduction

```bash
cd subprojects/algorithm-evolution-agent-lab
codefire scan --path . --json --metrics
```

Observed next action shape:

```json
{
  "command": "codefire context --changed --json",
  "kind": "context_changed",
  "target": {
    "changed_atoms": ["REQ-AUTO-031", "DES-AUTO-013"]
  }
}
```

## Why It Matters

Automation often collects command results in one process and executes next actions from another cwd. If the action command omits the path context, the tool can accidentally inspect or mutate a different repository/open directory.

## Workaround

Execute next actions only after restoring the cwd used for the original command, or manually add `--path <open-dir>` when the command supports it.

## Candidate Fix

Preserve the resolved path context in next actions. Either include `--path <original-or-resolved-open-dir>` in generated commands, or add a stable machine-readable `target.path` / `target.open_dir` to every action that requires repository context.

## Acceptance Criteria

- `scan --path <dir> --json` next_actions retain the path context.
- context, verify, and extinguish actions are safe to execute from a different cwd.
- JSON next_actions include machine-readable path/open-dir fields even if command text remains concise.
- Tests cover `scan --path` from outside and inside an open directory.

## Evidence

- Observed during cycle 2 dogfooding after `ClaimReviewQueue` produced 4 changed atoms and 6 open fires.
