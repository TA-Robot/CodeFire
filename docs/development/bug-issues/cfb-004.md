# CFB-004: Verify details should expose the failing targets

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |
| Type | ux |
| Area | Diagnostics |
| Observed while | Investigating duplicate Atom IDs, stale resolutions, and missing links |

## Observation

Plain `verify` failure counts did not show the concrete Atom, trace link, stale resolution, or failed check target.

## Impact

Users had to inspect active JSON state directly to discover what to fix next.

## Fix

`codefire verify --details` prints representative failure diagnostics and target identifiers.

## Evidence

- `test_verify_details_reports_missing_required_links`
- Duplicate Atom ID detail coverage in the verify test suite.
