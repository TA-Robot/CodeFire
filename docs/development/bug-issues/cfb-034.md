# CFB-034: Doctor and migrate disagree on repository health

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | high |
| Type | compatibility |
| Area | `doctor` / `migrate` |
| Observed while | checking algorithm repo layout after runbook work |

## Observation

Doctor reports blocking repository problems, while `migrate check` reports `compatible: true` and no blockers.

## Reproduction

```bash
codefire doctor . --json
codefire migrate check --json
```

## Why It Matters

Automation cannot tell which health signal should gate work.

## Workaround

Treat `verify` and `commit` as final gates.

## Candidate Fix

Unify the vocabulary and shared layout rules for doctor, migrate, and verify.

## Acceptance Criteria

- Doctor and migrate agree on blocker severity.
- Compatible-but-repairable states are represented consistently.

## Evidence

- Doctor returned blocking 3; migrate check returned compatible true and blockers [].
