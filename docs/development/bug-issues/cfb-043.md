# CFB-043: Commit dry-run blocker path returns plain text

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | high |
| Type | automation-json |
| Area | `commit --dry-run --json` |
| Observed while | checking commit readiness before extinguishing runbook fires |

## Observation

`commit -m ... --dry-run --json` emits plain text when verification blocks the commit.

## Reproduction

```bash
codefire commit -m 'dry run check' --dry-run --json
```

## Why It Matters

Automation cannot read blocker counts, diagnostics, or next actions from the failed dry-run.

## Workaround

Run `verify --json` first.

## Candidate Fix

Return `ok:false` command_result envelope for blocked commit dry-run.

## Acceptance Criteria

- `--json` always produces JSON for success and failure.
- Blocked dry-run includes verification summary and next actions.

## Evidence

- CLI returned `error: commit blocked: verification failed or consistency blockers remain`.
