# CFB-056: Batch extinguish help does not expose the required wrapper schema

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |
| Type | UX / automation-json |
| Area | extinguish batch / help / diagnostics |
| Observed while | extinguishing `ExperimentIterationPlanner` fires |

## Observation

`codefire extinguish --help` shows only `codefire extinguish --batch <file> ...`. It does not show that JSON must be an object with `version` and `fires`, nor that limited YAML must use the same wrapper concept. A natural top-level JSON array and a natural top-level YAML sequence both failed.

## Reproduction

```bash
cat >/tmp/fires.json <<'JSON'
[
  {"fire": "FIRE-...", "resolution": "verified-by-test", "rationale": "tests pass"}
]
JSON

codefire extinguish --batch /tmp/fires.json --path . --json
```

The command routes this to the wrong shape and reports a parser error. The working shape is:

```json
{
  "version": 1,
  "fires": [
    {"id": "FIRE-...", "resolution": "verified-by-test", "rationale": "tests pass"}
  ]
}
```

## Why It Matters

Agents naturally generate array batches. Without a help example or schema diagnostic, they need to inspect source or docs before using batch extinguish safely.

## Workaround

Use the object wrapper shape with `version: 1` and `fires: [...]`.

## Candidate Fix

Add `codefire extinguish --batch --help` or extend `codefire extinguish --help` with a compact schema example. When the parser sees a top-level array, return a diagnostic that names the required wrapper.

## Acceptance Criteria

- Help shows a valid minimal JSON batch example.
- Top-level array errors say the input must be an object with `version` and `fires`.
- The same guidance is available in JSON diagnostics when `--json` is used.

## Fix

- `codefire extinguish --help` now includes a compact `{"version":1,"fires":[...]}` JSON example.
- Batch JSON detection treats both `{` and `[` as JSON starts, so top-level arrays no longer fall into the limited YAML parser.
- Top-level JSON arrays return a `batch_schema_error` diagnostic with a `show_batch_schema` next action that points back to `codefire extinguish --help`.

## Verification

```bash
cargo fmt --check
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
./install.sh --prefix /home/devuser/.local
codefire extinguish --help | rg -n "Batch JSON example|\\{\\\"version\\\":1,\\\"fires\\\""
tmp=$(mktemp); printf '[]' > "$tmp"; codefire extinguish --batch "$tmp" --path . --json || true; rm -f "$tmp"
```

## Evidence

- Top-level YAML sequence failed with `invalid batch YAML: unsupported root key '- fire' at line 1`.
- Top-level JSON array failed with `invalid batch YAML: expected key: value at line 1`.
- Wrapper JSON with `version` and `fires` succeeded.
