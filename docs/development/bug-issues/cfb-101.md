# CFB-101: no supported close command for feature open directories

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |
| Type | ux |
| Area | Branch lifecycle / Close |
| Observed while | branch-per-feature dogfood in `algorithm-evolution-agent-lab` |

## Observation

After sealing and merging a feature branch, `codefire close --help` returned:

```text
error: unsupported command: close
```

The feature branch remains `open-clean` and the feature open directory remains on disk. The CLI spec also lists `codefire discard <branch>` and `codefire close <branch> --discard`, but command dispatch and capabilities do not expose a supported close/discard lifecycle surface.

## Reproduction

```bash
cd /workspace/project/subprojects/algorithm-evolution-agent-lab-feature-nameaudit-summary-line
codefire close --help
codefire discard feature/nameaudit-summary-line
```

## Why It Matters

The intended branch-per-feature workflow creates one open directory per new development task. Without a supported close command, completed feature work leaves open registry entries and directories behind, or requires manual cleanup that can corrupt CodeFire state.

## Workaround

Fixed in branch workflow burn-down. Older binaries should avoid manual registry edits unless necessary.

## Candidate Fix

Implement branch lifecycle commands that safely close an open-clean directory and update the open registry. Destructive discard behavior should be explicit, documented, and guarded.

## Acceptance Criteria

- `codefire close --help` returns exit 0 and documents close behavior.
- `codefire discard --help` or documented `close --discard` behavior is available if discard remains part of the spec.
- Closing an open-clean branch removes or marks the open registry entry consistently.
- Dirty/open-burning branches are rejected unless an explicit discard option exists.
- Branch records and sealed commits remain intact.

## Evidence

- Observed on 2026-06-12 after merging `feature/nameaudit-summary-line` into `main`.
- Fixed by adding `codefire close <branch>` and `codefire discard <branch>` dispatch/help/capabilities plus guarded close implementation.
- Regression: `crates/codefire-cli/src/tests.rs::close_branch_closes_clean_open_dir_and_discard_allows_dirty_state`.
