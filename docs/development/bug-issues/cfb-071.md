# CFB-071: health and storage commands reject common --path option

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | ux |
| Area | CLI Path Contract |
| Observed while | checking repository health/storage during `ClaimAuditTrailBuilder` dogfooding |

## Observation

Several repository-targeting commands reject `--path` even though status, scan, verify, branch list, evidence, and other surfaces accept it.

## Reproduction

```bash
codefire storage --path /workspace/project/subprojects/algorithm-evolution-agent-lab --json
codefire doctor --path /workspace/project/subprojects/algorithm-evolution-agent-lab --quick --json
codefire migrate check --path /workspace/project/subprojects/algorithm-evolution-agent-lab --json
```

Observed:

```text
error: unsupported storage report option: --path
error: unsupported doctor option: --path
error: unsupported migrate option: --path
```

## Why It Matters

AI tools tend to use one path-passing pattern across commands. A command family that targets a repo/open directory but rejects `--path` makes scripts brittle. The failure is also plain text, so JSON automation cannot classify it.

## Workaround

Use positional paths where supported, or `cd` into the target before running the command.

## Candidate Fix

Adopt a shared path option parser for repo/open targeting commands. For commands that intentionally do not support `--path`, return a JSON envelope when `--json` is requested.

## Acceptance Criteria

- `storage --path <path> --json` works.
- `doctor --path <path> --json` works.
- `migrate check --path <path> --json` works.
- Unsupported path forms with `--json` return structured diagnostics, not plain text.

## Evidence

- Observed during cycle 2 dogfooding from `/workspace/project` while targeting the algorithm open directory.
- Reproduced again on 2026-06-07 during `FrontierExperimentPlanner` dogfooding: `storage --path . --json`, `doctor --path . --json`, and `migrate check --path . --json` each returned plain text unsupported option errors.
