# CFB-002: Python method atom IDs need class ownership

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | high |
| Type | bug |
| Area | Python Atom extraction |
| Observed while | `CodexPlanner.propose` and `StaticPlanner.propose` existed in the same file |

## Observation

Python method atoms were derived as ownerless function IDs such as `CODE:path::def:<method>`. Two classes with the same method name therefore produced duplicate Atom IDs.

## Impact

Valid Python object-oriented code could fail verification and block commits because unrelated class methods collided.

## Fix

The Python extractor tracks class ownership and derives method IDs with the class-qualified name.
