# CFB-073: context bounded output lacks total and omitted counts

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |
| Type | automation-contract |
| Area | Context / Bounded Output |
| Observed while | inspecting changed context during `ClaimAuditTrailBuilder` dogfooding |

## Observation

`codefire context --changed --path . --limit 2 --json` truncates atoms, fires, scan changed atoms, and scan open fires. It sets boolean flags under `data.truncated`, but it does not report total, returned, or omitted counts for each truncated collection.

## Reproduction

```bash
cd subprojects/algorithm-evolution-agent-lab
codefire context --changed --path . --limit 2 --json
```

Observed:

```json
{
  "data": {
    "atoms": [/* 2 items */],
    "fires": [/* 2 items */],
    "truncated": {
      "atoms": true,
      "fires": true,
      "scan_changed_atoms": true,
      "scan_open_fires": true
    }
  }
}
```

## Why It Matters

Bounded output is useful, but automation needs to know how much was omitted. A boolean tells the tool to be cautious, but not whether the omitted work is one item or hundreds.

## Workaround

Run `scan --json` first and use its counters or full arrays to recover changed/open fire counts.

## Candidate Fix

Add bounded collection metadata for each limited array: `total_count`, `returned_count`, and `omitted_count`.

## Acceptance Criteria

- context JSON reports total/returned/omitted counts for atoms, fires, changed atoms, and open fires.
- Tests cover `--limit` with truncation.
- next_actions can point to a full-output or higher-limit command when omitted_count is positive.

## Evidence

- Observed during cycle 2 dogfooding with 4 changed atoms and 6 open fires limited to 2.

## Fix

- Fixed in the global burn-down pass.
- `context --json` now returns `data.summary` with total, returned, and omitted counts for atoms, trace links, fires, changed atoms, and open fires.
- Trace links also report omitted endpoint counts, and context output returns `context_expand` next actions when a higher limit is needed.
- Text context output now prints omitted counts and a follow-up context command when bounded output omits data.
