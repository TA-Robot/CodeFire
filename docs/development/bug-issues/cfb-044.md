# CFB-044: Diff JSON is not wrapped in command result envelope

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |
| Type | automation-json |
| Area | `diff --json` |
| Observed while | comparing sealed base commits |

## Observation

`diff main main --json` emits raw `codefire_diff` rather than `codefire.command_result.v1`.

## Reproduction

```bash
codefire diff main main --json
```

## Why It Matters

Automation must special-case diff because `ok`, `exit_code`, `diagnostics`, and `schema` are absent.

## Workaround

Fixed. `codefire diff ... --json` now returns a command result envelope with the existing diff payload under `data`.

## Candidate Fix

Implemented. Diff payload is wrapped in the command result envelope and placed under `data`.

## Fix

- `diff --json` returns top-level `schema`, `command`, `ok`, `exit_code`, `repo`, `diagnostics`, and `next_actions`.
- Existing `codefire_diff` payload remains available under `data`.
- Impact-driven diff next actions are also copied to the top-level envelope.

## Acceptance Criteria

- `diff --json` has the same top-level envelope as other automation commands.
- Existing diff payload remains available under `data`.

## Evidence

- Output top-level fields were `type=codefire_diff`, `left`, `right`, `impact`, `trace`, and no `ok`.
- Fixed on 2026-06-10 in the global burn-down pass.
- Regression coverage: `show_and_diff_local_branches`.
