# CFB-041: List command lacks JSON output

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |
| Type | automation-json |
| Area | `list` |
| Observed while | enumerating algorithm repo state |

## Observation

`list --json` is rejected as an unsupported option.

## Reproduction

```bash
codefire list --json
```

## Why It Matters

AI agents need machine-readable branch/open listings without reading internal files.

## Workaround

Fixed. Use `codefire list --json` from a repository or open directory.

## Candidate Fix

Implemented `list --json` as a command_result envelope.

## Fix

- `codefire list --json` returns local branch and opened worktree summaries.
- `codefire list <path> --json` can target a repository/open directory explicitly.
- `codefire list <remote-project-url> --json` returns remote branch summaries.
- Error cases in remote JSON mode return structured command_result failure envelopes.

## Acceptance Criteria

- `list --json` returns branches, open worktrees, and head commits.
- Error cases also use JSON envelope when requested.

## Evidence

- CLI returned `unsupported option: --json`.
