# CFB-001: Stale resolution refresh requires a first-class workflow

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | high |
| Type | bug |
| Area | Extinguish / stale resolution |
| Observed while | Moving `StaticPlanner` in `algorithm-evolution-agent-lab` made an already-extinguished fire stale |

## Observation

After a fire had been extinguished, later source movement changed the resolution basis. `verify` reported stale resolutions, but the normal extinguish workflow did not make it easy to refresh the same fire against the current basis.

## Impact

The branch could show `Open fires: 0` while still being blocked from commit by stale resolutions. This made a clean-looking branch require internal-state knowledge to recover.

## Fix

`codefire extinguish --refresh` updates stale resolution basis explicitly and supersedes the older resolution.
