# CFB-039: Single evidence add has no dry-run

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |
| Type | ux |
| Area | `evidence add --dry-run` |
| Observed while | checking runbook evidence before writing |

## Observation

Single evidence add with `--dry-run` is rejected unless `--batch` is used.

## Reproduction

```bash
codefire evidence add --from-command '<command>' --dry-run --json
```

## Why It Matters

Evidence writes are side-effecting, and users cannot preview a single command capture.

## Workaround

Create a batch file or run the command outside CodeFire first.

## Candidate Fix

Implement dry-run operation plan for single evidence add.

## Fix

v0.8 removes the batch-only dry-run restriction. Single evidence add validates inputs and returns an operation plan without running the command or writing evidence/artifact objects.

## Acceptance Criteria

- Single evidence add supports `--dry-run --json`.
- Dry-run validates cwd, command shape, output limits, and intended object writes.

## Evidence

- CLI returned `evidence add --dry-run requires --batch`.
- Regression coverage: `evidence_add_single_dry_run_returns_plan_without_writing_object`.
- Verification: `cargo test -p codefire-cli --bin codefire-rs -- --nocapture`.
