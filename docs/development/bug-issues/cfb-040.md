# CFB-040: Show JSON option returns text

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | automation-json |
| Area | `show --json` |
| Observed while | reading algorithm base commit information |

## Observation

`show main --json` prints text instead of JSON.

## Reproduction

```bash
codefire show main --json
```

## Why It Matters

Automation using `jq` fails with parse errors.

## Workaround

Parse text output or read `.codefire` objects directly.

## Candidate Fix

Wrap show output in `codefire.command_result.v1`.

## Acceptance Criteria

- `show --json` always emits valid JSON.
- Text mode remains unchanged.

## Evidence

- Output began with `Object: main@CF-COMMIT...`.
