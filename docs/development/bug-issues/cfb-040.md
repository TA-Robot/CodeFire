# CFB-040: Show JSON option returns text

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |
| Type | automation-json |
| Area | `show --json` |
| Observed while | reading algorithm base commit information |

## Observation

`show main --json` prints text instead of JSON.

## Reproduction

```bash
codefire show main --json
```

## Why It Matters

Automation using `jq` fails with parse errors.

## Workaround

Fixed. Use `codefire show <target> --json`.

## Candidate Fix

Implemented. Show output now has a typed JSON payload inside `codefire.command_result.v1`.

## Fix

- Added `show` option parsing so `--json` is no longer treated as a target.
- Added typed `codefire_show_result` data with commit id, label, message, parents, roots, file/atom counts, certificate, and signature summary.
- Text mode still renders the existing human summary.

## Acceptance Criteria

- `show --json` always emits valid JSON.
- Text mode remains unchanged.

## Evidence

- Output began with `Object: main@CF-COMMIT...`.
- Fixed on 2026-06-10 in the global burn-down pass.
- Regression coverage: `show_and_diff_local_branches`, `parse_diff_args_accepts_algorithm_forms`.
