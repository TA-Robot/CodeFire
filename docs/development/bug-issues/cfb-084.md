# CFB-084: migrate --metrics --json returns a plain text unsupported option error

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | automation-json |
| Area | Migrate / JSON Failure |
| Observed while | checking migration compatibility from the algorithm project during CodeFire improvement cycle 2 |

## Observation

`codefire migrate check <path> --json --metrics` returned a plain text error: `error: unsupported migrate option: --metrics`. The command did not return a `codefire.command_result.v1` envelope despite `--json` being present.

## Reproduction

```bash
codefire migrate check /workspace/project/subprojects/algorithm-evolution-agent-lab --json --metrics
```

Observed:

```text
error: unsupported migrate option: --metrics
```

## Why It Matters

Migrate is a health/recovery command that AI tools may run with standard observability flags. Plain text failure prevents structured recovery, and it is inconsistent with successful `migrate check --json` output.

## Workaround

Run migrate without `--metrics`.

## Candidate Fix

Route migrate parser errors through the JSON failure envelope when `--json` is requested. Then either support metrics for migrate or return a structured unsupported-option diagnostic.

## Acceptance Criteria

- `migrate check <path> --json --metrics` never emits plain text only.
- unsupported migrate options include command, option, exit code, and next recovery action in JSON.
- help documents whether metrics are supported.

## Evidence

- Observed on 2026-06-07 with `codefire migrate check /workspace/project/subprojects/algorithm-evolution-agent-lab --json --metrics`.
