# CFB-008: Storage growth needs visible artifact guidance

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |
| Type | storage |
| Area | Storage / Artifacts |
| Observed while | Checking `.codefire` storage size in `algorithm-evolution-agent-lab` |

## Observation

The sealed object store was small at the observed scale, but ML experiment logs, metrics, and model artifacts could grow it rapidly if stored directly.

## Impact

Large binary or experiment artifacts could make CodeFire repositories expensive to move, clone, or inspect.

## Fix

Storage reporting highlights large objects and external artifact references. Heavy artifacts should be tracked through metadata references rather than embedded payloads.

## Evidence

- Storage report large-object warning and external artifact summary.
- `bug-backlog.md` CFB-008 row.
