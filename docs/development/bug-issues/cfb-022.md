# CFB-022: Successful verify should print a blocking summary

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |
| Type | ux |
| Area | UX / Verify Output |
| Observed while | Running `verify --details --blocking-only` after extinguishing dogfood fires |

## Observation

Successful verification printed only `Verification passed.` without the zero counts that mattered for audit logs.

## Impact

CI logs and sub-agent logs did not show whether open fires, stale resolutions, missing evidence refs, and blocking checks were all zero.

## Fix

Successful verify output now includes the key blocking summary counters and base context.

## Evidence

- Global burn-down scan/verify summary fixes.
- `current-cycle-burn-down-plan.md` CFB-022 entry.
