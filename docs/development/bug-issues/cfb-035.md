# CFB-035: Migrate planned actions do not fully match doctor issues

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | compatibility |
| Area | `migrate check` |
| Observed while | comparing doctor and migrate output |

## Observation

Doctor reported missing `artifact_refs`, `evidence`, and `idempotency`; migrate planned actions did not clearly mirror every doctor issue.

## Reproduction

```bash
codefire doctor . --json
codefire migrate check --json
```

## Why It Matters

Following the migration plan may not obviously clear doctor findings.

## Workaround

Run doctor again after migration and inspect directory state manually.

## Candidate Fix

Generate doctor findings and migration planned actions from the same layout definition.

## Acceptance Criteria

- Every repairable doctor layout issue maps to a migration action or explicit no-op explanation.
- Migrate output references the corresponding doctor issue kind.

## Evidence

- Migrate showed planned directory creation while doctor listed a broader set of missing directories.
