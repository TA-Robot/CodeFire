# CFR-171: consistency claimとcertificate proof kindがmachine-readableに束縛されない

## Summary

| Field | Value |
|---|---|
| Status | investigating |
| Milestone | backlog parked; bounded branch/show data-schema slice satisfied by `MS-adoption-wedge` |
| Severity | high |
| Type | product-correctness / proof-contract |
| Area | Claim descriptor / Verification certificate |
| Source | RVC-001/019 |

## Problem

Verification/certificateはpassed/failedとcountsを持つが、どのsubject、semantic profile、policy、coverage、
execution trust、proof kindについて何をclaimしたかを一つのmachine-readable descriptorとして固定しない。
embedded result、portable evidence、legacy compatibilityを利用者が同じ「verified」と誤読し得る。

## Root Cause and Deduplication

CFB-014-016、CFR-121/122/159、ADR-013/014がoutcomeとcross-root consistencyを強化した。本件はそれらを
再計算せず、claim/proof boundaryをversioned subjectへ束縛するdownstream contractである。

## Required Fix

- claim type、subject digest、base/head、semantic/profile versions、policy/coverage digest、trust/proof kindを持つdescriptor。
- certificate、verify JSON、review pack、show/explainが同じdescriptorをlossless projectionする。
- embedded/local、signed portable、legacy/unprovenをcapabilityとhuman languageで区別する。
- Store validatorがdescriptor/root/certificate mismatchとunknown critical claimをfail closedにする。

## Acceptance Criteria

- 同じsealed commitの全surfaceがbyte/digest-equivalent claim descriptorを返す。
- subject/policy/coverage/proof kindの一field tamperでsealed validationが失敗する。
- legacy recordは持たないclaimを追加せず、unknown critical claim versionをrejectする。
- independent minimal consumerがsource knowledgeなしにclaim scopeと不足証拠を判定できる。

## Test Plan

- descriptor canonical vectors、tamper table、legacy/current read matrix。
- verify→commit→show/review/explain cross-surface equality。
- minimal consumer conformance fixture。
