# CFR-032: 短いHTTP bodyを不完全リクエストとして拒否していない

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | high |
| Type | correctness-risk |
| Area | HTTP server |
| Source | `crates/codefire-cli/src/http.rs:379` |

## Problem

readが0でbreakした後、`content_length` に満たないbody sliceをJSON parseしている。

## Why It Matters

truncated JSONがparse errorになるだけでなく、短いがvalidなJSON断片の場合に意図しないbodyとして扱う余地がある。

## Failure Mode / Review Hypothesis

通常ケースでは動いても、境界条件や並行実行でCodeFireの整合性表示・保存結果がずれる可能性がある。truncated JSONがparse errorになるだけでなく、短いがvalidなJSON断片の場合に意図しないbodyとして扱う余地がある。

## Code Evidence

- Primary source: `crates/codefire-cli/src/http.rs:379`
- Observed implementation fact: readが0でbreakした後、`content_length` に満たないbody sliceをJSON parseしている。

## Recommended Fix

response側と同様に、body長が `Content-Length` 未満なら明示的に `incomplete HTTP request body` を返す。
