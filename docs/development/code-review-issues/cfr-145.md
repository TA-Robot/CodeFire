# CFR-145: fire operation planが全item詳細を無制限に含む

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | performance |
| Area | Fire dry-run |
| Source | `crates/codefire-cli/src/fire.rs:412`, `crates/codefire-cli/src/fire.rs:424` |

## Problem

fire operation planは対象fireの詳細を全件JSONに含める。大量fireを扱うrepoではdry-run出力が巨大化する。

## Impact

dry-runはAI toolが頻繁に呼ぶため、巨大JSONはtoken、メモリ、ログ保存量を増やす。

## Recommended Fix

summaryとsampleを分け、defaultでは上限付きsampleを返す。全件が必要な場合は明示flagを使う。

## Acceptance Criteria

- dry-run planに `item_count`, `sample_items`, `truncated` がある。
- default出力サイズが対象件数に線形増加しない。
- full detail要求時のflagがhelpにある。

## Test Plan

- 1000件fire fixtureでplan sizeが上限内になることを確認する。
