# CFR-066: install先prefixの安全性チェックが弱い

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | security |
| Area | Install |
| Source | `install.sh:79` |

## Problem

`prefix` から `install_dir` を作り、そのままinstallする。path正規化や既存file owner/mode確認はない。

## Why It Matters

誤ったprefixやsymlink経由で想定外の場所へ上書きする可能性がある。

## Failure Mode / Review Hypothesis

悪意ある入力、誤設定、共有環境での実行により、可用性・機密性・認証境界が弱くなる可能性がある。 誤ったprefixやsymlink経由で想定外の場所へ上書きする可能性がある。

## Code Evidence

- Primary source: `install.sh:79`
- Observed implementation fact: `prefix` から `install_dir` を作り、そのままinstallする。path正規化や既存file owner/mode確認はない。

## Recommended Fix

prefix canonicalize、symlink warning、overwrite policyを追加する。
