# CFR-152: storage next_actionsがautomation共通schemaを使っていない

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | maintainability |
| Area | Storage report |
| Source | `crates/codefire-cli/src/storage.rs:241`, `crates/codefire-cli/src/automation.rs:402` |

## Problem

storage reportのnext_actionsは `id/description/context` を返し、automation共通のaction schemaと一致しない。

## Impact

storage warningからdoctorやcleanupへ進む導線をAI toolが汎用処理できない。

## Recommended Fix

storage next_actionsを共通型へ移行し、threshold、object type、recommended commandをstructured contextへ入れる。

## Acceptance Criteria

- storage next_actionsが共通schemaになる。
- threshold超過時のactionがpath付きcommandを持つ。
- no warning時の空配列またはnoop契約が明確。

## Test Plan

- quick/full storage JSON schema snapshotを追加する。
