# CFR-147: evidence dry-run planが解決後cwdを返さない

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |
| Type | ux |
| Area | Evidence |
| Source | `crates/codefire-cli/src/evidence.rs:399`, `crates/codefire-cli/src/evidence.rs:416` |

## Problem

evidence dry-runのoperation planは入力されたcwd optionを中心に表示し、実際に解決されるcwdやdefault cwdを明確に返さない。

## Impact

証跡commandは実行directoryで意味が変わる。dry-runで解決後cwdが分からないと、証跡の再現性を判断できない。

## Recommended Fix

dry-run planに `requested_cwd`, `resolved_cwd`, `cwd_source` を追加する。default cwdの方針もdocsに明記する。

## Acceptance Criteria

- dry-run JSONから実行予定cwdが一意に分かる。
- cwdが存在しない場合はdry-run時点で診断される。
- apply結果とdry-run planのcwdが一致する。

## Test Plan

- cwd指定あり/なしのdry-run snapshot testを追加する。

## Fix

Evidence dry-run now resolves command cwd before producing the operation plan. The plan includes `requested_cwd`, `cwd`, `resolved_cwd`, `cwd_source`, `repo_relative_cwd`, and `allow_failed_command`, and the applied result uses the same cwd resolution path.
