# CFR-002: CLI内部型が `main.rs` に集中している

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | high |
| Type | maintainability |
| Area | CLI domain model |
| Source | `crates/codefire-cli/src/main.rs:970` |

## Problem

`Status`、`OpenOptions`、`ExtinguishOptions`、`CommitOptions`、`MergeResult`、`OpenContext` など、多数の型定義が `main.rs` に置かれている。

## Why It Matters

型の所有moduleが不明確になり、他moduleが `super::*` に依存しやすくなる。

## Failure Mode / Review Hypothesis

今後の修正で責務混在や差分衝突が増え、不変条件を守りにくくなる。型の所有moduleが不明確になり、他moduleが `super::*` に依存しやすくなる。

## Code Evidence

- Primary source: `crates/codefire-cli/src/main.rs:970`
- Observed implementation fact: `Status`、`OpenOptions`、`ExtinguishOptions`、`CommitOptions`、`MergeResult`、`OpenContext` など、多数の型定義が `main.rs` に置かれている。

## Recommended Fix

`state`, `commands`, `merge`, `open`, `errors` など責務単位へ型を移動する。

## Implementation Notes

- Fixed in v0.7: CLI option/result/context model types were moved from `main.rs` into `crates/codefire-cli/src/cli_model.rs`.
- The module owns `Status`, branch/open/clone/commit/extinguish/patch/merge option/result types, `LockOptions`, `OpenContext`, and scan/verify execution wrappers.
- `main.rs` re-exports the model for existing feature modules while keeping fields `pub(crate)` and imports explicit at module boundaries.
- Boundary: AI agent運用機能やmarketplaceをCodeFire本体へ入れず、整合性管理・履歴封印・自動化tool向けI/Oの改善として扱う。
- Related issues: none identified in this review batch.

## Acceptance Criteria

- `main.rs` からdomain型の大半が消える。
- 各moduleが必要な型だけを明示importする。
