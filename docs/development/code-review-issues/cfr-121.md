# CFR-121: sealed commit validationがresolution_ledger rootを必須化していない

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | high |
| Type | correctness-risk |
| Area | Commit validation |
| Source | `crates/codefire-store/src/lib.rs:445`, `crates/codefire-store/src/lib.rs:467` |

## Problem

`REQUIRED_COMMIT_ROOTS` がcommit時に生成される `resolution_ledger` を必須rootとして検証していなかった。

## Impact

fire解決履歴が欠けたcommit objectをvalidation済みとして扱う可能性がある。review、explain、history再構築が「存在しているはずの監査root」を前提にできない。

## Code Evidence

- `crates/codefire-store/src/lib.rs:445`: required rootsに `resolution_ledger` がない。
- `crates/codefire-store/src/lib.rs:467`: root validation側は `resolution_ledger` typeを認識している。

## Recommended Fix

commit schemaの必須root setに `resolution_ledger` を追加する。legacy commitはdoctor/migrateで明示診断する。

## Fix

Current sealed commit validation now requires `resolution_ledger` for `root_schema_version >= 2`, and the store test helper writes an empty resolution ledger for valid current commits. Legacy commits without `root_schema_version` remain readable so existing repositories can still be opened and migrated. Current commits missing that root are rejected with `missing root resolution_ledger`.

## Acceptance Criteria

- [x] `resolution_ledger` 欠損の新形式commitをvalidationが拒否する。
- [x] commit生成、doctor、remote uploadが同じrequired root定義を参照する。
- [x] legacy扱いの診断とmigration方針が文書化される。
