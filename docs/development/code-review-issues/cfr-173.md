| Field | Value |
|---|---|
| Status | investigating |

| Severity | medium |

## Problem

sealed historyとopen working state、Fire、verification metricsは存在するが、checkpoint頻度、Fireのactionability、
false/noisy warning、解決lead time、consistency defect prevention、support costを一つのprivacy-preserving protocolで
測定していない。内部機能数やtest数をproduct successと誤認し、stop/narrow判断ができない。

## Root Cause and Deduplication

CFB-005-007/018/027/101/105/114、CFR-061/062/145、ADR-002/005を再利用する。CFR-168のwork countersと
CFR-171のclaim descriptorを前提にし、telemetry収集を無断でproductへ追加しない。

## Required Fix

- no-checkpoint、small-checkpoint、Fire resolutionの再現可能dogfood cohortとtask definitions。
- actionable/duplicate/obsolete/false Fire分類、lead time、wrong action、evidence quality、seal recovery metrics。
- raw source/secretを収集しないlocal aggregate/evidence formatとretention decision。
- 事前のsuccess、narrow、stop thresholdsとdecision owner。

## Acceptance Criteria

- 同一task cohortをbaseline/currentで再実行し、task/input/result digestと失敗logを保存する。
- Fire usefulnessを件数ではなく正しいaction/defect prevention/lead timeで評価する。
- privacy/retention boundaryを越えず、missing dataをsuccessとして扱わない。
- threshold未達なら機能追加で取り繕わず、claim/scopeをnarrowまたはstopするterminal decisionを記録する。

## Test Plan

- historical/dogfood task replay、metric calculator deterministic tests。
- missing/failed/negative result retention。
- decision record/checkerとroadmap update。
