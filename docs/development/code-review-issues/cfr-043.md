# CFR-043: command cwdのdefaultがopen/repo rootではなく現在dirになっている

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |
| Type | correctness-risk |
| Area | Evidence capture |
| Source | `crates/codefire-cli/src/evidence.rs:322` |

## Problem

`command_cwd` 未指定時に `std::env::current_dir()` を使っている。

## Why It Matters

別directoryから `--path` を指定して実行したとき、証跡commandが想定外のcwdで走る可能性がある。

## Failure Mode / Review Hypothesis

通常ケースでは動いても、境界条件・並行実行・破損状態でCodeFireの整合性判断がずれる可能性がある。 別directoryから `--path` を指定して実行したとき、証跡commandが想定外のcwdで走る可能性がある。

## Code Evidence

- Primary source: `crates/codefire-cli/src/evidence.rs:322`
- Observed implementation fact: `command_cwd` 未指定時に `std::env::current_dir()` を使っている。

## Recommended Fix

default cwdをrepo rootまたはopen dirに寄せ、現在dirを使う場合はJSONへ明示する。
