# CFR-013: object検索が全subdir走査になっている

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |
| Type | performance |
| Area | Object lookup |
| Source | `crates/codefire-store/src/lib.rs:188` |

## Problem

`object_record_path` は object id からtype/subdirを使わず、objects_root配下の全directoryを順に確認する。

## Why It Matters

object typeやsubdir数が増えるほどread pathが不要に遅くなる。

## Failure Mode / Review Hypothesis

入力規模が増えたときに処理時間またはメモリ使用量が急増する可能性がある。object typeやsubdir数が増えるほどread pathが不要に遅くなる。

## Code Evidence

- Primary source: `crates/codefire-store/src/lib.rs:188`
- Observed implementation fact: `object_record_path` は object id からtype/subdirを使わず、objects_root配下の全directoryを順に確認する。

## Recommended Fix

object ID prefixからsubdirを逆引きする、またはobject indexを持つ。
