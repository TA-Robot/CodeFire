# CFR-064: install.shにdry-runがない

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |
| Type | compatibility |
| Area | Install |
| Source | `install.sh:9` |

## Problem

installerはparse後すぐbuild/installし、変更予定だけを確認するmodeを持たない。

## Why It Matters

CIやroot権限環境で事前確認しづらい。

## Failure Mode / Review Hypothesis

インストール名、URL、保存形式、fallback方針の揺れで既存運用が壊れる可能性がある。 CIやroot権限環境で事前確認しづらい。

## Code Evidence

- Primary source: `install.sh:9`
- Observed implementation fact: installerはparse後すぐbuild/installし、変更予定だけを確認するmodeを持たない。

## Recommended Fix

`--dry-run` でbuild/install/completionの予定pathを表示する。

## Acceptance Criteria

- 予定されるbinary/completion pathが表示される。
- dry-runではbuild、mkdir、install、completion生成を行わない。
