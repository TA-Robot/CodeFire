# CFR-042: 証跡commandがshell経由で実行される

## Summary

| Field | Value |
|---|---|
| Status | fixed in v0.7 |
| Severity | medium |
| Type | security |
| Area | Evidence capture |
| Source | `crates/codefire-cli/src/evidence.rs:327` |

## Problem

`--from-command` の値は `sh -c` に渡され、引数配列として保存・実行されない。

## Why It Matters

設定ファイルやbatch由来のcommandを扱う場合、意図しないshell展開や注入リスクがある。

## Failure Mode / Review Hypothesis

悪意ある入力、誤設定、共有環境での実行により、可用性・機密性・認証境界が弱くなる可能性がある。 設定ファイルやbatch由来のcommandを扱う場合、意図しないshell展開や注入リスクがある。

## Code Evidence

- Primary source: `crates/codefire-cli/src/evidence.rs:327`
- Observed implementation fact: `--from-command` の値は `sh -c` に渡され、引数配列として保存・実行されない。

## Recommended Fix

string shell modeとargv modeを分け、batchではargv形式を推奨する。

## Implementation Notes

- Priority: 公開remoteや共有環境で使う前にリスク評価し、可能なら早めに潰す。
- First step: 拒否すべき入力・許可すべき入力を先にテストで固定する。
- Boundary: AI agent運用機能やmarketplaceをCodeFire本体へ入れず、整合性管理・履歴封印・自動化tool向けI/Oの改善として扱う。
- Related issues: [CFR-041](cfr-041.md), [CFR-043](cfr-043.md)

## Acceptance Criteria

- argv形式のevidence commandを指定できる。
- shell形式は明示的に `shell: true` として扱う。

## Test Plan

- argv command capture test。

## v0.7 Partial Progress

- evidence command JSONに `mode: "shell"` と `shell: true` を保存し、shell modeであることを明示した。
- argv形式指定として `--from-argv <program> --argv <arg>...` とbatch `from_argv` を追加した。argv modeはshellを使わず、evidence command JSONに `mode: "argv"`、`shell: false`、`argv` 配列を保存する。shell展開されないことをテストで固定した。
