# CFR-034: upload時のtmp directory名が衝突し得る

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | correctness-risk |
| Area | HTTP remote |
| Source | `crates/codefire-cli/src/http.rs:581` |

## Problem

tmp pathはprocess idとhead hashから作られ、同process内で同じhead uploadが並行すると同じpathになり得る。

## Why It Matters

片方が `remove_dir_all` して他方の検証中tmpを消す可能性がある。

## Failure Mode / Review Hypothesis

通常ケースでは動いても、境界条件や並行実行でCodeFireの整合性表示・保存結果がずれる可能性がある。片方が `remove_dir_all` して他方の検証中tmpを消す可能性がある。

## Code Evidence

- Primary source: `crates/codefire-cli/src/http.rs:581`
- Observed implementation fact: tmp pathはprocess idとhead hashから作られ、同process内で同じhead uploadが並行すると同じpathになり得る。

## Recommended Fix

random nonceまたはrequest idをtmp pathに含める。
