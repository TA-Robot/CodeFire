# CFR-170: automation outcomeとnext actionがtyped executable contractでない

## Summary

| Field | Value |
|---|---|
| Status | investigating |
| Milestone | M1 admitted (local action contract slice only) |
| Severity | medium |
| Type | automation-contract |
| Area | Exit/diagnostic vocabulary / Next actions / Migration |
| Source | RVC-034/035, CFB-133 |

## Problem

command result envelopeは共通化されたが、severity/blocking語彙、custom lock/error envelopes、next actionの
string command/placeholder、precondition/mutation authorityがまだsurfaceごとに異なる。`migrate apply`は成功後も
適用前planのreview actionを返し、postconditionではなくhistorical planからactionを作るdriftを実証した。

## Root Cause and Deduplication

CFB-074/100、CFR-095/140-155、CFR-161はshape/outcomeの基盤を作った。本件はactionを安全に実行できる
typed requestとして、authoritative outcome/postconditionからのみ導出する残差をownerにする。

## Required Fix

- success/warning/blocking/errorの一つのtyped outcome/diagnostic vocabulary。
- next actionにargv、mode、target subject、expected precondition、mutation class、idempotency/dry-run capabilityを持たせる。
- human command stringはtyped argvからのprojectionに限定する。
- action reducerをcurrent postconditionから作り、planned/applied historical auditと分離する。

## Acceptance Criteria

- 全command representative matrixでprocess exit、envelope exit、ok、diagnostic blocking、primary outcomeが一致する。
- placeholder commandをmachine-executableとして誤表示せず、実行可能actionはshell parsingなしにargvで使える。
- stale precondition/targetは実行前にreject/replanでき、mutating actionはauthorityとdry-run supportを宣言する。
- CFB-133 successful applyはnext action 0、partial applyはremaining actionだけを案内する。

## Test Plan

- command/outcome/action decision tableとschema compatibility。
- migration dry/apply/replay/partial failure integration。
- shell metacharacter/path、stale precondition、human projection regressions。

## Triage Checklist

- [x] automation driftとCFB-133を再現した
- [x] 既存envelope issueとdeduplicateした
- [x] typed action scopeを凍結した

## Implementation Progress

- The CFB-133 migration slice now derives actions from mode plus current `remaining_actions` rather
  than treating historical `planned_actions` as unfinished work. Successful apply/replay produces no
  action; dry-run still produces apply; check still produces review; failed apply produces a bounded
  retry carrying remaining/applied/blocker counts.
- Focused migration tests, the existing command-envelope regression, workspace check, strict Clippy,
  formatting, source-doc, and diff checks pass. This closes only the migration drift slice; the shared
  typed executable-action schema and representative all-command decision matrix remain open here.
