# CFR-141: verify成功時next_actionが変更有無を見ずcommitを勧める

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | ux |
| Area | Next actions |
| Source | `crates/codefire-cli/src/automation.rs:301`, `crates/codefire-cli/src/automation.rs:310` |

## Problem

verificationがpassedの場合、changed atom数やpending fireの有無を十分に見ずにcommit next_actionを出す。

## Impact

clean repoで不要なcommitをAI toolが試行し、失敗や空commit計画を増やす。

## Recommended Fix

next_action生成にstate summaryを渡し、changed atoms、open fires、fresh scan、pending evidenceに基づいてcommit/scan/status/noopを選ぶ。

## Acceptance Criteria

- clean verified stateではcommitではなくnoop/status summaryを返す。
- changesありのpassed stateではcommit actionが具体的なtargetを持つ。
- next_action理由がmachine-readableに残る。

## Test Plan

- clean repo verifyとchanged repo verifyでnext_actionが分岐するtestを追加する。
