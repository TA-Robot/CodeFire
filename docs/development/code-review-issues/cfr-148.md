# CFR-148: doctorがactive state file欠損を明示診断しない

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | correctness-risk |
| Area | Doctor |
| Source | `crates/codefire-cli/src/doctor/checks.rs:388`, `crates/codefire-cli/src/doctor/checks.rs:399` |

## Problem

doctorはactive state directory内の個別JSONを存在すれば検証するが、期待されるstate fileが欠けている場合の診断が弱い。

## Impact

active state file欠損を正常な空状態と区別できず、status/contextが古い状態や欠落状態を前提にする可能性がある。

## Recommended Fix

active state schema registryを定義し、required/optional fileを区別して欠損診断を出す。

## Acceptance Criteria

- active state directoryがあるのにrequired fileが欠ける場合doctorがwarning/errorを出す。
- 初期repoの未生成状態と壊れた欠損状態を区別できる。
- 診断に再生成commandが含まれる。

## Test Plan

- active state file欠損fixtureでdoctor診断を確認する。
