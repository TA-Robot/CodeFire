# CFR-156: migrateのJSON object走査にlimitやquick modeがない

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | performance |
| Area | Migration |
| Source | `crates/codefire-cli/src/migration.rs:361`, `crates/codefire-cli/src/migration.rs:380` |

## Problem

migration checkはrepo内JSON fileを再帰的に集めるが、巨大repo向けのlimit、quick mode、progress summaryがない。

## Impact

古い/壊れたrepoほどmigration checkが必要なのに、全走査で遅くなり運用に乗りにくい。

## Recommended Fix

quick check、full check、max files、sampling summaryを導入する。full modeではprogress/metricsを返し、途中打ち切りをJSONに明示する。

## Acceptance Criteria

- large repoでquick migration checkが短時間に終わる。
- full checkの走査件数と打ち切り有無がJSONに出る。
- max limit超過時のdiagnosticが出る。

## Test Plan

- synthetic large JSON tree fixtureでquick/fullの挙動を確認する。
