# CFR-159: certificate resultの用語がverification resultとずれている

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | compatibility |
| Area | Commit certificate |
| Source | `crates/codefire-cli/src/main.rs:3728`, `crates/codefire-store/src/lib.rs:437` |

## Problem

verification resultは `passed/failed` 系だが、commit certificateは `consistent` を使っており、結果語彙が揃っていない。

## Impact

AI toolやremote policyがどのfieldを信頼すべきか迷う。schema evolutionでもmapping漏れが起きやすい。

## Recommended Fix

certificate resultをverification resultと同じ語彙にするか、`certificate_status` と `verification_result` を別fieldとして意味を分ける。

## Acceptance Criteria

- result語彙の意味がschema docsに明記される。
- JSON consumerがverification/certificate結果を同じenumで扱える。
- legacy `consistent` のmigration方針がある。

## Test Plan

- certificate schema snapshotとlegacy fixture testを追加する。
