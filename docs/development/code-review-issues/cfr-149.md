# CFR-149: doctorがstate/open_firesの整合性を検証しない

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | correctness-risk |
| Area | Doctor |
| Source | `crates/codefire-cli/src/doctor/checks.rs:420`, `crates/codefire-cli/src/doctor/checks.rs:452` |

## Problem

doctorはactive state JSONのshapeを検証するが、`state` と `open_fires`、changed atom数、verification結果の意味的整合性までは検証しない。

## Impact

shapeが正しくても意味的に壊れたactive stateがstatusやcontextを誤らせる。

## Recommended Fix

active state invariantを定義し、`open-clean` ならopen fires 0、`open-fire` ならopen fires > 0などを検証する。

## Acceptance Criteria

- 矛盾したactive state fixtureをdoctorが検出する。
- status再計算で修復可能な場合はnext_actionを出す。
- invariantがdocsに記載される。

## Test Plan

- state/open_fires矛盾fixtureをdoctor testに追加する。
