# CFR-125: link batch dry-runのinvalid結果が成功envelopeに包まれる

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | high |
| Type | correctness-risk |
| Area | Batch link |
| Source | `crates/codefire-cli/src/link_batch.rs:117`, `crates/codefire-cli/src/main.rs:613` |

## Problem

link batch dry-runで入力がinvalidでも、commandとしては成功扱いのJSON envelopeに包まれる経路がある。

## Impact

AI toolはexit codeやtop-level `ok` を信頼するため、apply不可のplanを成功と誤認し、次の適用stepへ進む可能性がある。

## Code Evidence

- `crates/codefire-cli/src/link_batch.rs:117`: invalid diagnosticsを含むdry-run resultを返す。
- `crates/codefire-cli/src/main.rs:613`: dry-run resultを成功resultとしてJSON出力している。

## Recommended Fix

dry-run validation失敗はtop-levelで `ok=false` または `validation_failed` として表現する。payload内の `valid=false` だけに依存しない。

## Acceptance Criteria

- invalid dry-runはtop-level resultで失敗またはblockedとして判定できる。
- valid dry-runのみapply可能planとして扱われる。
- diagnosticsの件数と対象IDがmachine-readableに残る。

## Test Plan

- invalid batch dry-runのJSON contract testを追加する。
