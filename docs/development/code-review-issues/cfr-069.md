# CFR-069: idempotency recordのretention/GCが見えない

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | performance |
| Area | Remote idempotency |
| Source | `crates/codefire-cli/src/remote/idempotency.rs:269` |

## Problem

record pathはcommand/key配下に蓄積されるが、TTLや削除方針が見えない。

## Why It Matters

長期運用remoteでidempotency領域が増え続ける可能性がある。

## Failure Mode / Review Hypothesis

入力規模が増えると処理時間、I/O、メモリ使用量が急増する可能性がある。 長期運用remoteでidempotency領域が増え続ける可能性がある。

## Code Evidence

- Primary source: `crates/codefire-cli/src/remote/idempotency.rs:269`
- Observed implementation fact: record pathはcommand/key配下に蓄積されるが、TTLや削除方針が見えない。

## Recommended Fix

remote GCにidempotency retentionを追加し、storage reportへ件数/bytes/oldestを出す。
