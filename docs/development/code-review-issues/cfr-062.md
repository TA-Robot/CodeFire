| Field | Value |
|---|---|

| Severity | medium |
| Type | performance |
| Area | Metrics |

## Problem

metricsは常に `cache enabled: false` を表示する。

## Why It Matters

cacheが未実装なのか無効なのか、将来有効化時の互換性が曖昧。

## Failure Mode / Review Hypothesis

入力規模が増えると処理時間、I/O、メモリ使用量が急増する可能性がある。 cacheが未実装なのか無効なのか、将来有効化時の互換性が曖昧。

## Code Evidence

- Primary source: `crates/codefire-cli/src/metrics.rs:81`
- Observed implementation fact: metricsは常に `cache enabled: false` を表示する。

## Recommended Fix

cache statusを実装状態/disabled reason/entry countに分ける。
