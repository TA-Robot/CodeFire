# CFR-037: commit signatureの時刻検証が文字列比較に依存している

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |
| Type | security |
| Area | Signatures |
| Source | `crates/codefire-cli/src/signatures.rs:392` |

## Problem

`signed_at < not_before` と `signed_at > not_after` を文字列比較で判定している。

## Why It Matters

ISO表記揺れやtimezone表現が入ると時刻順序を誤判定する可能性がある。

## Failure Mode / Review Hypothesis

悪意ある入力または遅い接続によって、remote/serverの可用性や署名境界が弱くなる可能性がある。ISO表記揺れやtimezone表現が入ると時刻順序を誤判定する可能性がある。

## Code Evidence

- Primary source: `crates/codefire-cli/src/signatures.rs:392`
- Observed implementation fact: `signed_at < not_before` と `signed_at > not_after` を文字列比較で判定している。

## Recommended Fix

request signatureと同じくUTC秒へparseして比較する。

## Implementation Notes

- Priority: 機能追加の前後で一緒に片付ける。単独修正でも価値はあるが、関連領域の改修時にまとめると効率がよい。
- First step: 入力上限、timeout、認証/署名境界を先にテストで固定する。
- Boundary: AI agent運用機能やmarketplaceをCodeFire本体へ入れず、整合性管理・履歴封印・自動化tool向けI/Oの改善として扱う。
- Related issues: [CFR-036](cfr-036.md)

## Acceptance Criteria

- `Z` 形式以外はrejectまたは正規化される。
- not_before/not_afterもparse errorを返す。
- `signed_at` / `not_before` / `not_after` はUTC秒へparseして数値比較する。
