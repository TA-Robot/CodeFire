# CFR-099: batch JSON parserがtop-level arrayをJSONとして扱わない

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | compatibility |
| Area | Batch parser |
| Source | `crates/codefire-cli/src/batch.rs:262` |

## Problem

batch extinguish parserは入力textが `{` で始まる場合だけJSON parserへ進み、top-level array JSONはYAML parser側へ流れる。JSON batchとして自然な `[{...}]` 形式を使うと、エラーが分かりにくくなる。

## Why It Matters

AI toolは配列を自然なbatch形式として生成することが多い。top-level arrayをJSONとして認識しないと、valid JSONなのにlimited YAML errorになり、修正指示が不正確になる。

## Failure Mode / Review Hypothesis

`[{"fire":"F-1", ...}]` がJSON parseではなくYAML parseへ渡される。user/toolはJSON syntaxが悪いのかCodeFire schemaが悪いのか判断できない。

## Code Evidence

- Primary source: `crates/codefire-cli/src/batch.rs:262`
- Observed implementation fact: JSON detection uses leading `{` rather than JSON parser first.
- Related source: `crates/codefire-cli/src/batch.rs:271`
- Observed implementation fact: JSON schema currently expects object with `fires` array.

## Recommended Fix

入力が `{` または `[` で始まる場合はJSON parserへ通す。top-level arrayを許可するか、明確なJSON schema errorとして「object with fires required」を返す。

## Implementation Notes

- Priority: medium。
- First step: top-level array inputのerror shape testを追加する。
- Boundary: YAML parserの拡張ではなくJSON detection/schema診断の改善。

## Acceptance Criteria
