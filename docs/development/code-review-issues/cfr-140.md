# CFR-140: verification diagnostic filterがpayloadを実際には絞り込まない

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | ux |
| Area | Verification JSON |
| Source | `crates/codefire-cli/src/automation.rs:173`, `crates/codefire-cli/src/automation.rs:186` |

## Problem

verification JSONに `diagnostic_filter` は付与されるが、diagnostics配列やsummaryがfilter条件に応じて実際に絞り込まれない。

## Impact

blockingだけ、warningだけといった取得を期待するAI toolが、後段で再filterする必要がある。

## Recommended Fix

filterを `diagnostics` に適用し、必要なら `unfiltered_summary` と `filtered_summary` を分ける。

## Acceptance Criteria

- `--diagnostic-filter blocking` でnon-blocking diagnosticsが除外される。
- summaryがfiltered/unfilteredのどちらか明確になる。
- filter未指定時は従来互換の全件出力になる。

## Test Plan

- mixed diagnostics fixtureでfilterごとの件数をassertする。
