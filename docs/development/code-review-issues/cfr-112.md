# CFR-112: file remote upload dry-runがremote layout/policy検証を省略する

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | high |
| Type | correctness-risk |
| Area | Remote upload dry-run |
| Source | `crates/codefire-cli/src/remote.rs:155` |

## Problem

file-backed remote uploadのdry-runは、実際のmutation前に行うremote layout作成/検証、policy、signature、permission、lock取得後再検証と同じチェックを完全には通らない。dry-run成功がapply成功を十分に予測しない。

## Why It Matters

AI toolはdry-runを信頼してapplyへ進む。dry-runでremote missingやpolicy rejectionを見落とすと、本番uploadで失敗し、改善サイクルの自動化が不安定になる。

## Failure Mode / Review Hypothesis

存在しないremote projectや不正layoutに対してupload dry-runがplan成功を返すが、apply時にlayout/policy/signatureで失敗する。dogfoodingではupload dry-run envelopeのrepo/next_actions不足も観測された。

## Code Evidence

- Primary source: `crates/codefire-cli/src/remote.rs:155`
- Observed implementation fact: `upload_branch` owns dry-run and apply paths.
- Related source: `crates/codefire-cli/src/remote.rs:982`
- Observed implementation fact: remote layout helpers exist but dry-run coverage must be aligned.

## Recommended Fix

dry-runを「副作用なしの本番前検証」として定義し、remote root existence/layout/policy/signature/permissionを読み取り範囲で検証する。作成が必要なlayoutはplanned actionとして明示し、成功扱いを分ける。

## Implementation Notes

- Priority: high。
- First step: missing/invalid remoteに対するupload dry-run testを追加する。
- Boundary: dry-runはremote filesを作成しない。
- Related issues: CFB-065, CFR-113.

## Acceptance Criteria

- invalid remote layoutでdry-runがwarning/errorを返す。
- dry-run successならapplyで事前条件系失敗が起きにくい。
- dry-run dataにvalidated checks一覧が出る。

## Test Plan

- file remote missing root、invalid layout、permission policy、signature required casesをdry-run/applyで比較する。

## Fix

- file remote upload dry-runにread-only precondition validationを追加し、既存remote projectの必須layoutとobject subdirを検査するようにした。
- remote projectがまだ存在しない場合は副作用なしに `missing_would_create` / `planned_create` としてplanの `validations` に明示する。
- 既存remote layoutが壊れている場合はdry-runでも `remote layout invalid` として失敗する。
- dry-run planに `validations` を追加し、検証済み/作成予定の前提条件をautomationから読めるようにした。
