# CFR-083: debug系commandがautomation envelopeを迂回している

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | maintainability |
| Area | Automation JSON |
| Source | `crates/codefire-cli/src/main.rs:155` |

## Problem

`atom-index`、`trace-graph`、`missing-links` は `serde_json::to_string_pretty` でraw JSONを直接出力する。`codefire.command_result.v1` envelope、diagnostics、exit code metadata、repo path、next_actionsを通らない。

## Why It Matters

これらはdebug commandでも、Atom/Trace/Policyの状態をAI toolが把握するために有用である。raw JSON commandが残ると、外部toolはcommandごとにschema分岐を持つ必要があり、JSON contractの一貫性が崩れる。

## Failure Mode / Review Hypothesis

debug commandをdogfood中に使うと、他commandと異なるJSON shapeが返り、automation pipelineが失敗する。将来debug commandが正式機能へ昇格した時に、互換性を壊さずenvelopeへ移行しにくくなる。

## Code Evidence

- Primary source: `crates/codefire-cli/src/main.rs:155`
- Observed implementation fact: debug command match arms print raw JSON directly.
- Related source: `crates/codefire-cli/src/automation.rs:9`
- Observed implementation fact: common envelope helper exists but these commands do not use it.

## Recommended Fix

debug commandにも `--json` envelopeを適用する。text modeが不要ならJSON envelopeをdefaultにするか、正式commandでないことをdocsに明記し、automation対象外として隠す。

## Implementation Notes

- Priority: medium。core state introspectionをdogfoodで使うため早めに整理する。
- First step: `atom-index` の現状shapeを固定するtestを追加する。
- Boundary: 新しいAI agent機能ではなく、既存CLI出力契約の統一。
- Related issues: CFR-081, CFR-071.

## Acceptance Criteria

- `atom-index`、`trace-graph`、`missing-links` がenvelopeまたは明示的なnon-contract commandとして扱われる。
- docsにautomation対象/非対象が記載される。
- raw JSON direct printが新規commandで増えないようreview ruleがある。
