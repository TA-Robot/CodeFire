# CFR-076: context depth traversalに出力上限がない

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | performance |
| Area | Context |

## Problem

selected_atom_idsはdepthを受け取り、選択Atom/links/firesをJSONに入れるが、最大Atom数/edge数の上限が見えない。

## Why It Matters

大きいtrace graphでcontext JSONが巨大化する。

## Failure Mode / Review Hypothesis

入力規模が増えると処理時間、I/O、メモリ使用量が急増する可能性がある。 大きいtrace graphでcontext JSONが巨大化する。

## Code Evidence

- Primary source: `crates/codefire-cli/src/context.rs:254`
- Observed implementation fact: selected_atom_idsはdepthを受け取り、選択Atom/links/firesをJSONに入れるが、最大Atom数/edge数の上限が見えない。

## Recommended Fix

depth上限、node/edge limit、省略summaryを追加する。
