# CFR-075: contextが固定時刻でscanを構築している

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | correctness-risk |
| Area | Context |
| Source | `crates/codefire-cli/src/context.rs:175` |

## Problem

context内の `build_scan_result` に `1970-01-01T00:00:00Z` を渡している。

## Why It Matters

context結果のfire metadataが実際のscanと違う可能性がある。

## Failure Mode / Review Hypothesis

通常ケースでは動いても、境界条件・並行実行・破損状態でCodeFireの整合性判断がずれる可能性がある。 context結果のfire metadataが実際のscanと違う可能性がある。

## Code Evidence

- Primary source: `crates/codefire-cli/src/context.rs:175`
- Observed implementation fact: context内の `build_scan_result` に `1970-01-01T00:00:00Z` を渡している。

## Recommended Fix

read-only preview用のfire生成ではcreated_atを持たない、またはactive fireを優先する。

- Priority: 関連領域を触るタイミングで一緒に片付ける。単独修正でも価値はある。
