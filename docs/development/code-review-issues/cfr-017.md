# CFR-017: fire UIDにSHA-1由来の短縮値が残っている

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | compatibility |
| Area | Fire model |
| Source | `crates/codefire-core/src/lib.rs:853`, `crates/codefire-core/src/lib.rs:1248` |

## Problem

`fire_uid` は `sha1_hex(key)[..12]` を使っている。

## Why It Matters

object IDはSHA-256なのにfire UIDだけ別hashで、長期的な一貫性と衝突余裕が弱い。

## Failure Mode / Review Hypothesis

インストール名、保存形式、旧実装との互換性が揺れたときに運用が壊れる可能性がある。object IDはSHA-256なのにfire UIDだけ別hashで、長期的な一貫性と衝突余裕が弱い。

## Code Evidence

- Primary source: `crates/codefire-core/src/lib.rs:853`, `crates/codefire-core/src/lib.rs:1248`
- Observed implementation fact: `fire_uid` は `sha1_hex(key)[..12]` を使っている。

## Recommended Fix

fire UIDもSHA-256 digestへ移行し、表示IDとは別の安定IDとして扱う。

- Priority: 機能追加の前後で一緒に片付ける。単独修正でも価値はあるが、関連領域の改修時にまとめると効率がよい。
