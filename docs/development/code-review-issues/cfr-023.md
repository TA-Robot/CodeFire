# CFR-023: trace link IDが生Atom ID連結で長大化・衝突曖昧化し得る

## Problem

link IDは `LINK-{from}-{type}-{to}` で、escapeやdigestを使っていない。

## Why It Matters

長いAtom IDでlink IDも長大化し、区切り文字を含むIDでは人間にも機械にも分解が曖昧になる。

## Failure Mode / Review Hypothesis

通常ケースでは動いても、境界条件や並行実行でCodeFireの整合性表示・保存結果がずれる可能性がある。長いAtom IDでlink IDも長大化し、区切り文字を含むIDでは人間にも機械にも分解が曖昧になる。

## Code Evidence

- Primary source: `crates/codefire-core/src/lib.rs:927`
- Observed implementation fact: link IDは `LINK-{from}-{type}-{to}` で、escapeやdigestを使っていない。

## Recommended Fix

link identityをcanonical JSON digestへ寄せ、表示用summaryと内部IDを分ける。
