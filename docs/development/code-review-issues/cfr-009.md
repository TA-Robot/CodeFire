# CFR-009: help/next actionが `codefire-rs` に固定されている

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | compatibility |
| Area | CLI naming |
| Source | `crates/codefire-cli/src/automation.rs:40`, `crates/codefire-cli/src/main.rs:1321` |

## Problem

next actionやusage文字列に `codefire-rs` が直接埋まっている。

## Why It Matters

installed binaryが `codefire` の場合、AI toolやユーザーが存在しないcommandを実行する可能性がある。

## Failure Mode / Review Hypothesis

インストール名、保存形式、旧実装との互換性が揺れたときに運用が壊れる可能性がある。installed binaryが `codefire` の場合、AI toolやユーザーが存在しないcommandを実行する可能性がある。

## Code Evidence

- Primary source: `crates/codefire-cli/src/automation.rs:40`, `crates/codefire-cli/src/main.rs:1321`
- Observed implementation fact: next actionやusage文字列に `codefire-rs` が直接埋まっている。

## Recommended Fix

binary nameを定数化し、実行名または配布名に合わせる。

## Implementation Notes

- Priority: 機能追加の前後で一緒に片付ける。単独修正でも価値はあるが、関連領域の改修時にまとめると効率がよい。
- First step: 既存object/CLI/保存形式の読み取り互換性を壊さない移行計画を作る。
- Boundary: AI agent運用機能やmarketplaceをCodeFire本体へ入れず、整合性管理・履歴封印・自動化tool向けI/Oの改善として扱う。
- Related issues: none identified in this review batch.

## Acceptance Criteria

- install後の `codefire --help` とnext actionが一致する。
