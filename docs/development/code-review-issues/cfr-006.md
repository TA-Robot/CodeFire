## Summary

| Field | Value |
|---|---|

| Severity | medium |
| Type | ux |

## Problem

成功時は `Verification passed.` のみを出してreturnする。

## Why It Matters

CIログやサブプロセスログでopen fire数、stale resolution数、baseなどを再確認できない。

## Failure Mode / Review Hypothesis

人間とAI toolのログ解釈がずれ、次に実行すべき操作を誤る可能性がある。CIログやサブプロセスログでopen fire数、stale resolution数、baseなどを再確認できない。

## Code Evidence

- Primary source: `crates/codefire-cli/src/verification.rs:63`
- Observed implementation fact: 成功時は `Verification passed.` のみを出してreturnする。

## Recommended Fix

成功時にも `Open fires: 0`、`Stale resolutions: 0`、`Failed checks: 0` などのsummaryを出す。

## Implementation Notes

- Priority: 機能追加の前後で一緒に片付ける。単独修正でも価値はあるが、関連領域の改修時にまとめると効率がよい。
- First step: 標準出力、JSON、next_actionsの3面で同じ意味を返すようにする。
- Boundary: AI agent運用機能やmarketplaceをCodeFire本体へ入れず、整合性管理・履歴封印・自動化tool向けI/Oの改善として扱う。
- Related issues: none identified in this review batch.
