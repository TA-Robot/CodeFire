# CFR-078: HTTP URL parserがIPv6 authorityを扱いにくい

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | correctness-risk |
| Area | HTTP parser |
| Source | `crates/codefire-cli/src/http.rs:248` |

## Problem

authorityを `rsplit_once(":")` でhost/portに分ける。

## Why It Matters

IPv6 literalや角括弧付きauthorityで誤parseする可能性がある。

## Failure Mode / Review Hypothesis

通常ケースでは動いても、境界条件・並行実行・破損状態でCodeFireの整合性判断がずれる可能性がある。 IPv6 literalや角括弧付きauthorityで誤parseする可能性がある。

## Code Evidence

- Primary source: `crates/codefire-cli/src/http.rs:248`
- Observed implementation fact: authorityを `rsplit_once(":")` でhost/portに分ける。

## Recommended Fix

標準URL parser導入、またはIPv6 bracket parserを実装する。
