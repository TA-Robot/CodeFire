# CFR-040: 低レベルutilityが各crate/moduleに重複している

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | maintainability |
| Area | Config/time/hash |

## Problem

time formatting、hex encode、hash helper、path encodeなどが複数moduleに散っている。

## Why It Matters

微妙な差異や修正漏れが起き、securityやcompatibilityの基盤部分が揺れる。

## Failure Mode / Review Hypothesis

今後の修正で責務混在や差分衝突が増え、不変条件を守りにくくなる。微妙な差異や修正漏れが起き、securityやcompatibilityの基盤部分が揺れる。

## Code Evidence

- Primary source: `crates/codefire-cli/src/main.rs:4656`, `crates/codefire-cli/src/remote.rs:1428`, `crates/codefire-store/src/lib.rs:390`
- Observed implementation fact: time formatting、hex encode、hash helper、path encodeなどが複数moduleに散っている。

## Recommended Fix

`codefire-util` crateまたはstore/coreの適切なmoduleへ低レベルutilityを集約する。

## Implementation Notes

- Priority: 機能追加の前後で一緒に片付ける。単独修正でも価値はあるが、関連領域の改修時にまとめると効率がよい。
- First step: 責務境界を先に切り、動作変更を伴わない分割commitから始める。
- Boundary: AI agent運用機能やmarketplaceをCodeFire本体へ入れず、整合性管理・履歴封印・自動化tool向けI/Oの改善として扱う。
- Related issues: none identified in this review batch.

## Acceptance Criteria

- SHA/hex/time/path encodeの共通APIがある。
- 既存重複実装が削除される。

- utility単体テストと既存golden test。
