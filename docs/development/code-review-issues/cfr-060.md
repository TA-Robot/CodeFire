# CFR-060: private key parserがPKCS8/RSAのみ対応

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | low |
| Type | compatibility |
| Area | TLS |
| Source | `crates/codefire-cli/src/http_tls.rs:85` |

## Problem

private key読み込みはpkcs8とrsa private keyだけを見る。

## Why It Matters

EC keyなど一般的なPEM形式でserve TLSが使えない可能性がある。

## Failure Mode / Review Hypothesis

インストール名、URL、保存形式、fallback方針の揺れで既存運用が壊れる可能性がある。 EC keyなど一般的なPEM形式でserve TLSが使えない可能性がある。

## Code Evidence

- Primary source: `crates/codefire-cli/src/http_tls.rs:85`
- Observed implementation fact: private key読み込みはpkcs8とrsa private keyだけを見る。

## Recommended Fix

対応形式を明示し、必要なら追加parserを導入する。
