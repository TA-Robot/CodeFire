# CFR-044: artifact_refに絶対pathを保存している

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | security |
| Area | Evidence artifacts |
| Source | `crates/codefire-cli/src/evidence.rs:267` |

## Problem

artifact ref payloadに `path: absolute` とdefault `uri: absolute path` を保存する。

## Why It Matters

ユーザー名、workspace構造、機密pathがsealed objectやremoteへ流出する可能性がある。

## Failure Mode / Review Hypothesis

悪意ある入力、誤設定、共有環境での実行により、可用性・機密性・認証境界が弱くなる可能性がある。 ユーザー名、workspace構造、機密pathがsealed objectやremoteへ流出する可能性がある。

## Code Evidence

- Primary source: `crates/codefire-cli/src/evidence.rs:267`
- Observed implementation fact: artifact ref payloadに `path: absolute` とdefault `uri: absolute path` を保存する。

## Recommended Fix

repo相対pathと外部URIを分け、絶対path保存は明示opt-inにする。

## Implementation Notes

- Priority: 公開remoteや共有環境で使う前にリスク評価し、可能なら早めに潰す。
- First step: 拒否すべき入力・許可すべき入力を先にテストで固定する。
- Boundary: AI agent運用機能やmarketplaceをCodeFire本体へ入れず、整合性管理・履歴封印・自動化tool向けI/Oの改善として扱う。
