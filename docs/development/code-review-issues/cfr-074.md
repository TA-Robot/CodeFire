# CFR-074: context snapshotがscan resultを再構築している

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |

## Problem

contextはactive scanを読むのではなく、atom index/trace/firesから `build_scan_result` を再実行する。

## Why It Matters

scan commandの副作用・fire numbering・stateとcontext表示がずれる可能性がある。

## Failure Mode / Review Hypothesis

機能追加時に同じ仕様を複数箇所へ反映する必要があり、修正漏れや不変条件破壊につながる。 scan commandの副作用・fire numbering・stateとcontext表示がずれる可能性がある。

## Code Evidence

- Primary source: `crates/codefire-cli/src/context.rs:147`
- Observed implementation fact: contextはactive scanを読むのではなく、atom index/trace/firesから `build_scan_result` を再実行する。

## Recommended Fix

read-only context用snapshotとmutating scan用処理を明確に分ける。

## Acceptance Criteria

- contextがactive scanとの関係をJSONに示す。
- scan再構築で新規fire IDを作らないことを保証する。
- active `scan.json` がある場合はそれを読み、ない場合だけ `preview_recomputed` としてread-only preview scanを作る。
