# CFR-123: root validationがatom_indexやtrace_graphなどのpayload shapeを検証しない

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | high |
| Type | correctness-risk |
| Area | Object validation |
| Source | `crates/codefire-store/src/lib.rs:467` |

## Problem

`validate_root_references` は一部root typeだけを検査し、`atom_index`、`trace_graph`、`fire_delta`、`policy` などのshapeや到達性を検証していない。

## Impact

壊れたrootを持つcommitがremoteへpushされ、checkout/context/explain時に初めて壊れたJSONへ遭遇する。commit受理時点で止められない。

## Code Evidence

- `crates/codefire-store/src/lib.rs:467`: root typeごとのvalidationが限定的で、主要rootのschema検証が揃っていない。

## Recommended Fix

root type registryを作り、各root typeに `required`、`validator`、`legacy_policy` を持たせる。既知rootはpayload schemaまで検証する。

## Acceptance Criteria

- 既知root typeはobject存在だけでなくpayload shapeも検証される。
- validation結果がroot typeと理由をstructured diagnosticで返す。
- 新root type追加時にvalidator未登録をtestで検出できる。

## Test Plan

- 壊れた `atom_index` / `trace_graph` fixtureを追加する。
- root registry coverage testを追加する。
