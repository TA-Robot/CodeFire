# CFR-157: context atom traversalがlimitで落としたneighbor情報を説明しない

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | ux |
| Area | Context |
| Source | `crates/codefire-cli/src/context.rs:396`, `crates/codefire-cli/src/context.rs:425` |

## Problem

atom neighborhood traversalはlimit到達時に探索を止めるが、どのneighborが省略されたか、追加取得すべきdepth/limitが何かを返さない。

## Impact

AI toolが狭すぎるcontextで設計判断し、関連Atomやtrace linkを見落とす危険がある。

## Recommended Fix

limit到達時にfrontier size、omitted neighbor IDs sample、recommended next commandを返す。

## Acceptance Criteria

- limit到達時に省略されたneighbor数が分かる。
- 追加取得用next_actionがdepth/limit付きで出る。
- default limitの根拠がdocsにある。

## Test Plan

- branching graph fixtureでlimit到達時のomitted metadataをassertする。
