# CFR-065: completion生成失敗時にbinary installだけ完了した状態になる

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | correctness-risk |
| Area | Install |
| Source | `install.sh:104`, `install.sh:119` |

## Problem

binaryをinstallしてからcompletionを生成する。completion生成に失敗すると部分installになる。

## Why It Matters

インストール結果の原子性が弱く、再実行前に状態が中途半端になる。

## Failure Mode / Review Hypothesis

通常ケースでは動いても、境界条件・並行実行・破損状態でCodeFireの整合性判断がずれる可能性がある。 インストール結果の原子性が弱く、再実行前に状態が中途半端になる。

## Code Evidence

- Primary source: `install.sh:104`, `install.sh:119`
- Observed implementation fact: binaryをinstallしてからcompletionを生成する。completion生成に失敗すると部分installになる。

## Recommended Fix

tmp staging dirに配置してから最後にmoveする、またはpartial installを明示する。
