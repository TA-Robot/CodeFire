# CFR-063: install.shがrelease binaryの検証をしない

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | high |
| Type | maintainability |
| Area | Install |
| Source | `install.sh:104` |

## Problem

指定/ビルドしたbinaryをそのまま `install` し、versionやhelp smokeを確認しない。

## Why It Matters

壊れたbinaryや別binaryを `codefire` として配置する可能性がある。

## Failure Mode / Review Hypothesis

機能追加時に同じ仕様を複数箇所へ反映する必要があり、修正漏れや不変条件破壊につながる。 壊れたbinaryや別binaryを `codefire` として配置する可能性がある。

## Code Evidence

- Primary source: `install.sh:104`
- Observed implementation fact: 指定/ビルドしたbinaryをそのまま `install` し、versionやhelp smokeを確認しない。

## Recommended Fix

install前後に `--help` とversion/fingerprintを確認する。

## Implementation Notes

- Priority: v0.6 hardeningで優先的に扱う。整合性、security、性能、または配布品質に直接影響する。
- First step: 動作変更なしの分割または定数化から始める。
- Boundary: AI agent運用機能やmarketplaceをCodeFire本体へ入れず、整合性管理・履歴封印・自動化tool向けI/Oの改善として扱う。
- Related issues: [CFR-064](cfr-064.md), [CFR-065](cfr-065.md), [CFR-066](cfr-066.md)

## Acceptance Criteria

- install前にbinary identityを検証する。
- install後に `${prefix}/bin/codefire --help` smokeを行う。
- `--version` smokeでCodeFire identityを確認する。
