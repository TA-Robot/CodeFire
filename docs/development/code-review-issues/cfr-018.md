# CFR-018: display fire番号がledger長依存で安定性が弱い

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | correctness-risk |
| Area | Fire model |
| Source | `crates/codefire-core/src/lib.rs:833` |

## Problem

`fire_no` は `fires.len() + 1` から始まり、表示IDは `FIRE-{fire_no:03}` で採番される。

## Why It Matters

obsolete fireやledgerの持ち方に表示IDが影響され、ログ上の短い参照が長期安定しない。

## Failure Mode / Review Hypothesis

通常ケースでは動いても、境界条件や並行実行でCodeFireの整合性表示・保存結果がずれる可能性がある。obsolete fireやledgerの持ち方に表示IDが影響され、ログ上の短い参照が長期安定しない。

## Code Evidence

- Primary source: `crates/codefire-core/src/lib.rs:833`
- Observed implementation fact: `fire_no` は `fires.len() + 1` から始まり、表示IDは `FIRE-{fire_no:03}` で採番される。

## Recommended Fix

display IDにscan epochや短いkey suffixを含めるか、stable UIDを標準表示に併記する。
