# CFR-049: link batchは失敗時に全件diagnosticを返さない

## Summary

| Field | Value |
|---|---|
| Status | fixed in v0.7 |
| Severity | medium |
| Type | ux |
| Area | Link batch |
| Source | `crates/codefire-cli/src/link_batch.rs:211` |

## Problem

validationは最初に見つかったunknown atom/self-link/duplicateでreturnする。

## Why It Matters

大きいbatchで1件ずつ直す必要があり、AI toolの修正loopが増える。

## Failure Mode / Review Hypothesis

人間やAI toolがログ/JSONを誤解し、次の操作を誤る可能性がある。 大きいbatchで1件ずつ直す必要があり、AI toolの修正loopが増える。

## Code Evidence

- Primary source: `crates/codefire-cli/src/link_batch.rs:211`
- Observed implementation fact: validationは最初に見つかったunknown atom/self-link/duplicateでreturnする。

## Recommended Fix

全件validateしてdiagnostics配列でまとめて返すdry-run modeを追加する。

## v0.7 Resolution

link batch validationは全itemを走査して `self_link`、`unknown_from_atom`、`unknown_to_atom`、`duplicate_batch_link`、`existing_link` をdiagnostics配列へ集約するようにした。dry-runでは `valid: false` と item index付きdiagnosticsをJSON data/planへ返し、非dry-runでは同じdiagnosticsを集約したerrorで書き込み前に止める。multi-error fixture testを追加した。

## Implementation Notes
