# CFR-049: link batchは失敗時に全件diagnosticを返さない

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | ux |
| Area | Link batch |

## Problem

validationは最初に見つかったunknown atom/self-link/duplicateでreturnする。

## Why It Matters

大きいbatchで1件ずつ直す必要があり、AI toolの修正loopが増える。

## Failure Mode / Review Hypothesis

人間やAI toolがログ/JSONを誤解し、次の操作を誤る可能性がある。 大きいbatchで1件ずつ直す必要があり、AI toolの修正loopが増える。

## Code Evidence

- Primary source: `crates/codefire-cli/src/link_batch.rs:211`
- Observed implementation fact: validationは最初に見つかったunknown atom/self-link/duplicateでreturnする。

## Recommended Fix

全件validateしてdiagnostics配列でまとめて返すdry-run modeを追加する。
