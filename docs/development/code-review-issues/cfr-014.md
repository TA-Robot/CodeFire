# CFR-014: sealed commit検証がroot参照の到達性を限定的にしか見ていない

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | correctness-risk |
| Area | Commit validation |
| Source | `crates/codefire-store/src/lib.rs:299` |

## Problem

required rootの存在とroot typeは検証するが、manifest内blob、resolution内evidence、evidence内artifact refなどの到達object検証はstore側のsealed commit検証には含まれない。

## Why It Matters

rootだけ正しいが内部参照が欠けたcommitをsealed扱いする余地が残る。

## Failure Mode / Review Hypothesis

通常ケースでは動いても、境界条件や並行実行でCodeFireの整合性表示・保存結果がずれる可能性がある。rootだけ正しいが内部参照が欠けたcommitをsealed扱いする余地が残る。

## Code Evidence

- Primary source: `crates/codefire-store/src/lib.rs:299`
- Observed implementation fact: required rootの存在とroot typeは検証するが、manifest内blob、resolution内evidence、evidence内artifact refなどの到達object検証はstore側のsealed commit検証には含まれない。

## Recommended Fix

object graph traversalをstore crateへ寄せ、commit rootから到達するobjectを検証する。
