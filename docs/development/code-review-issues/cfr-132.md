# CFR-132: migrateのtarget formatがv0.6に固定されている

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | compatibility |
| Area | Migration |
| Source | `crates/codefire-cli/src/migration.rs:49`, `crates/codefire-cli/src/migration.rs:107` |

## Problem

migration commandはdefault/allowed targetが `v0.6` に固定されており、CodeFire本体のversion計画と独立して更新される。

## Impact

v0.7以降のrepo layoutやcommit schemaを導入しても、migration commandが古いtargetだけを案内し、現在形式への移行入口にならない。

## Recommended Fix

schema version registryを作り、current format、supported legacy formats、migration pathを一元化する。

## Acceptance Criteria

- current CodeFire formatへのmigration targetがhelp/JSONに出る。
- unsupported target errorがsupported listを返す。
- version追加時にmigration registry testが失敗して更新漏れを検出する。

## Test Plan

- `migrate check --target-format current --json` のcontract testを追加する。
