# CFR-038: Python旧本体とRust本体が二重実装として残っている

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |
| Type | maintainability |
| Area | Dual implementation |
| Source | `codefire:1`, `crates/codefire-cli/src/main.rs:1` |

## Problem

Python実装 `codefire` が約5,557行、Rust CLIが約4,691行あり、同じ概念を複数実装している。

## Why It Matters

仕様差分、fix漏れ、テスト対象の曖昧化が起きる。

## Failure Mode / Review Hypothesis

今後の修正で責務混在や差分衝突が増え、不変条件を守りにくくなる。仕様差分、fix漏れ、テスト対象の曖昧化が起きる。

## Code Evidence

- Primary source: `codefire:1`, `crates/codefire-cli/src/main.rs:1`
- Observed implementation fact: Python実装 `codefire` が約5,557行、Rust CLIが約4,691行あり、同じ概念を複数実装している。

## Recommended Fix

Python版をreference/fallbackとして凍結し、Rust defaultとの差分表と削除条件を作る。

## Implementation Notes

- Priority: 機能追加の前後で一緒に片付ける。単独修正でも価値はあるが、関連領域の改修時にまとめると効率がよい。
- First step: 責務境界を先に切り、動作変更を伴わない分割commitから始める。
- Boundary: AI agent運用機能やmarketplaceをCodeFire本体へ入れず、整合性管理・履歴封印・自動化tool向けI/Oの改善として扱う。
- Related issues: none identified in this review batch.

## Acceptance Criteria

- Python版に新機能を追加しない方針が文書化される。
- Rustで未実装のfallback項目が明示される。
- `known-limitations.md` にPython fallback freeze policy、許可されるPython変更範囲、Rust未実装fallback command list、fallback削除条件を明記する。
- `known_limitations_python_fallback_commands_stay_out_of_rust_cli` でfreeze policyの存在とfallback command list/Rust helpの整合を固定する。

## Test Plan

- `known_limitations_python_fallback_commands_stay_out_of_rust_cli`
- Python/Rust golden compatibility testsは、Python-created repository/object/remote formatの移行・incident responseに必要な範囲へ限定する。
