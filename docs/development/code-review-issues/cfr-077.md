# CFR-077: cf+http URL parserが余分なpath segmentを許容する

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |
| Type | correctness-risk |
| Area | Remote URL parser |
| Source | `crates/codefire-cli/src/http.rs:64` |

## Problem

`parse_cf_http_parts` は `parts.len() < min_parts` だけを見て、3要素を超えるpathも受け入れる。

## Why It Matters

typoを含むURLが意図せずbranch名等として解釈される可能性がある。

## Failure Mode / Review Hypothesis

通常ケースでは動いても、境界条件・並行実行・破損状態でCodeFireの整合性判断がずれる可能性がある。 typoを含むURLが意図せずbranch名等として解釈される可能性がある。

## Code Evidence

- Primary source: `crates/codefire-cli/src/http.rs:64`
- Observed implementation fact: `parse_cf_http_parts` は `parts.len() < min_parts` だけを見て、3要素を超えるpathも受け入れる。

## Recommended Fix

URL種別ごとにexact segment countを検証する。
