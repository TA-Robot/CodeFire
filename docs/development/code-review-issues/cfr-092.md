# CFR-092: branch subcommandのunsupported pathがstructured errorにならない

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | ux |
| Area | Branch CLI |
| Source | `crates/codefire-cli/src/main.rs:470` |

## Problem

`branch` は実質 `branch list` のみを扱い、`branch show --json` などのunsupported subcommandはplain usage errorへ落ちる。JSON指定時にもstructured diagnosticにならない。

## Why It Matters

branch管理はCodeFireの基本操作であり、AI toolはbranch一覧、branch詳細、open状態を問い合わせたい。unsupported commandでもmachine-readableに「未対応」「代替はbranch list」と返るべきである。

## Failure Mode / Review Hypothesis

`branch show --json` がtext errorを返し、automationがJSON parseに失敗する。helpにもbranchの能力が十分表れず、tool側のcapability discoveryが不安定になる。

## Code Evidence

- Primary source: `crates/codefire-cli/src/main.rs:470`
- Observed implementation fact: branch command dispatch handles `list` and otherwise returns usage-style error.
- Related source: `crates/codefire-cli/src/automation.rs:9`
- Observed implementation fact: common envelope exists but unsupported branch path does not use it.

## Recommended Fix

branch command moduleを作り、`list`、将来の`show`、unsupported subcommand errorを同じparser/diagnosticに通す。JSON指定時はCFR-081のerror envelopeを使う。

## Implementation Notes

- Priority: medium。
- First step: `branch show --json` の現状固定test。
- Boundary: branch show実装は別issueでもよいが、error shapeは共通化する。
- Related issues: CFB-058, CFR-081.

## Acceptance Criteria

- unsupported branch subcommandがJSON envelope errorを返す。
- diagnosticにsupported subcommandsと代替next actionがある。
- branch command helpが実装済みsubcommandと一致する。

## Test Plan

- `branch show --json`、`branch unknown --json`、`branch --help` testsを追加する。
