# CFR-139: commit/extinguish parserの--path形式が他commandと揃っていない

## Summary

| Field | Value |
|---|---|
| Status | open |
| Severity | medium |
| Type | compatibility |
| Area | CLI parser |
| Source | `crates/codefire-cli/src/main.rs:1451`, `crates/codefire-cli/src/main.rs:1548` |

## Problem

commit/extinguish系parserが `--path=value` を扱わず、他commandと異なるoption grammarになっている。

## Impact

path指定はほぼ全commandで使うため、ここが揺れるとAI agentのcommand生成失敗率が上がる。

## Recommended Fix

path/json/dry-run/metricsなどの共通option parserを導入し、command固有optionだけを各moduleに残す。

## Acceptance Criteria

- commit/extinguishで `--path=value` が使える。
- path parserの仕様が1箇所にまとまる。
- option grammar差分をCIで検出する。

## Test Plan

- commit/extinguishのequals形式path smoke testを追加する。
