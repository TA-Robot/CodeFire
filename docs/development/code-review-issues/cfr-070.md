# CFR-070: idempotency resultにplanを保存して再利用している

## Summary

| Field | Value |
|---|---|
| Status | fixed in v0.7 |
| Severity | medium |
| Type | correctness-risk |
| Area | Remote idempotency |
| Source | `crates/codefire-cli/src/remote/idempotency.rs:141` |

## Problem

replay時に保存済み `plan` をそのまま返す。

## Why It Matters

環境やremote状態が変わっても古いnext_actions/open_dir/pathを返す可能性がある。

## Failure Mode / Review Hypothesis

通常ケースでは動いても、境界条件・並行実行・破損状態でCodeFireの整合性判断がずれる可能性がある。 環境やremote状態が変わっても古いnext_actions/open_dir/pathを返す可能性がある。

## Code Evidence

- Primary source: `crates/codefire-cli/src/remote/idempotency.rs:141`
- Observed implementation fact: replay時に保存済み `plan` をそのまま返す。

## Recommended Fix

replay resultと現在context由来のnext_actionsを分ける。

## v0.7 Resolution

remote idempotency replayでは保存済みplanを再利用しないようにした。typed file-backed remote replayは `codefire_remote_idempotency_replay` planを生成し、HTTP remote replay resultには `replayed: true` を付与する。保存record側のresultからもplanを除外し、古いpath/next_actionsを現在操作の事実として扱わない。
