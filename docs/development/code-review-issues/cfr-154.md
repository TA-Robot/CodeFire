# CFR-154: plan result envelopeがoperation plan内next_actionsを昇格しない

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |
| Type | ux |
| Area | JSON envelope |
| Source | `crates/codefire-cli/src/main.rs:1277`, `crates/codefire-cli/src/main.rs:1301` |

## Problem

operation plan内にnext_actionsがあっても、top-level command result envelopeのnext_actionsへ昇格されない経路がある。

## Impact

AI toolはtop-level `next_actions` を共通入口として読むため、plan内部にだけactionがあると次の操作を見落とす。

## Recommended Fix

envelope生成時にoperation planのnext_actionsを検証・正規化し、top-levelにも同じactionを載せる。

## Fix

Implemented in the operation plan envelope burn-down:

- `plan_result_envelope` copies `data.plan.next_actions` to top-level `next_actions`.
- Regression coverage checks commit/extinguish/upload dry-run envelopes.
- Algorithm dogfood confirmed top-level `next_actions` for upload and commit dry-run.

## Acceptance Criteria

- dry-run系commandのtop-level next_actionsが空にならない。
- plan内部とtop-levelでaction IDが一致する。
- action抽出不能なpayloadはtestで検出される。

## Test Plan

- open/commit/upload dry-runのtop-level next_actions snapshotを追加する。
