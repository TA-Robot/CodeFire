# CFR-058: `CODEFIRE_TLS_INSECURE` が存在だけで証明書検証を無効化する

## Summary

| Field | Value |
|---|---|
| Status | fixed |
| Severity | medium |

## Problem

環境変数が存在すると値に関係なく `InsecureVerifier` を使う。

## Why It Matters

CIやshell環境に残った変数で意図せずTLS検証が無効化される可能性がある。

## Failure Mode / Review Hypothesis

悪意ある入力、誤設定、共有環境での実行により、可用性・機密性・認証境界が弱くなる可能性がある。 CIやshell環境に残った変数で意図せずTLS検証が無効化される可能性がある。

## Code Evidence

- Primary source: `crates/codefire-cli/src/http_tls.rs:20`
- Observed implementation fact: 環境変数が存在すると値に関係なく `InsecureVerifier` を使う。

## Recommended Fix

`CODEFIRE_TLS_INSECURE=1` のみ許可し、warningを出す。
