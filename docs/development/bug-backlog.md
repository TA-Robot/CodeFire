# CodeFire Bug Backlog

このファイルは、CodeFire自身を実プロジェクト管理に使いながら見つかった不具合、バグに近いUX、修正候補を管理する。

詳細issueは `docs/development/bug-issue-template.md` に従い、`docs/development/bug-issues/cfb-000.md` の1 issue 1 fileで管理する。このファイルの表は全体サマリとtriage索引として扱う。

## Status

- `open`: 未修正
- `investigating`: 再現条件や修正方針を確認中
- `fixed`: 修正済み
- `wontfix`: 現時点では仕様として扱う
