## Implementation Notes

### HTTPS

Do not duplicate HTTP route logic.
The preferred implementation is to keep `crates/codefire-cli/src/http.rs` route dispatch shared and swap only the transport:

- parse `cf+http://` and `cf+https://` into a shared remote URL model
- use plain `TcpStream` for HTTP
- wrap `TcpStream` with TLS only for HTTPS
- keep response parsing and JSON error handling shared
- support normal certificate verification by default
- allow `CODEFIRE_TLS_INSECURE=1` only for local self-signed smoke

### Signatures

Use Python v0.2 behavior as the oracle:

- commit signature fields and signing payload must remain object-ID compatible
- key object policy must support `secret`, `signers`, `not_before`, `not_after`, `status`, and `require_history`
- remote upload/apply must reject unsigned or invalid branch heads when policy requires signatures
- request signatures must cover operation, actor, target, timestamp, nonce, and key id
- nonce replay cache must be stored under the remote project and enforced for all mutating remote routes

### Installer

The installer switch must be conservative:

- never remove Python fallback unless explicitly requested
- install Rust binary as `codefire`
- install Python fallback as `codefire-py`
- keep bash/zsh completion install behavior
- document how to choose Python fallback explicitly during incident response
